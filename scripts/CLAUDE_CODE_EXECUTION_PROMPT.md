# Claude Code 実行プロンプト

以下の仕様書を確認した上で、
UAP公開文書 翻訳・要約プロジェクト用の
最小PDFページ画像化ツールを実装してください。

## 参照必須ファイル

- PROJECT_SPEC.md
- scripts/PDF_TO_IMAGES_SPEC.md
- scripts/CLAUDE_CODE_REQUEST.md

## 今回の実装対象

scripts/pdf_to_images.py

## 今回の目的

raw_pdf に保存されたPDFを、
ページ単位PNG画像へ変換し、
page_images 配下へ保存すること。

## 完成条件

- raw_pdf 内のPDFを検出できる
- PDFごとにサブフォルダを作成
- 全ページをPNG保存
- 元PDF名は変更しない
- エラー時も処理継続
- エラーログを表示
- Mac Studio ローカル環境で動作
- Python3 で動作
- 文系非エンジニアでも再実行可能

## 非対象

今回は以下を実装しない。

- OCR
- 翻訳
- 要約
- note整形
- GUI
- PDF自動ダウンロード

## セキュリティ・運用ルール

- chmod 777 を使用しない
- root 実行を前提にしない
- 必要最小限の権限で動作
- 元PDFを削除・変更しない
- 処理内容をコメントで明記
- 文系非エンジニア向けに分かりやすく説明

## 必須事項

以下も出力してください。

1. 必要ライブラリ
2. インストール方法

6. テスト結果

まずは1PDFで正常動作確認を行い、
その後に複数PDF対応へ拡張してください。

また、
「なぜその実装にしたのか」
を非エンジニア向けに説明してください。
