# Claude Code 実装依頼

## 目的

UAP公開文書 翻訳・要約プロジェクトにおいて、
PDFをページごとのPNG画像へ変換する最小ツールを作成したい。

## 背景

対象PDFは以下のような混在資料を含む。

- タイプされた報告書
- 手書きメモ
- 新聞・雑誌切り抜き
- スタンプ付き文書
- 管理票
- 写真・図版

そのため、まずはOCR前段階として、
「PDFをページ単位画像へ安定変換すること」を優先したい。

## 実装対象

scripts/pdf_to_images.py

## 入力

~/Documents/UAP_TRANSLATION_PROJECT/raw_pdf/

に保存されたPDF。

## 出力

~/Documents/UAP_TRANSLATION_PROJECT/page_images/

配下へ、
PDFごとのサブフォルダを作成し、
各ページをPNG保存する。

例:

page_images/
└── 65_hs1-834228961_62-hq-83894_section_10/
    ├── page_0001.png
    ├── page_0002.png
    └── page_0003.png

## 完成条件

1. raw_pdf 内のPDFを検出できる
2. PDFごとにサブフォルダ作成
3. 全ページをPNG保存
4. 元PDFファイル名は変更しない
5. エラー時は処理継続
6. エラーログ表示
7. Mac Studio ローカル環境で動作
8. Python3 で動作
9. 文系非エンジニアでも再実行可能

## 非対象

今回は以下を実装しない。

- OCR
- 翻訳
- 要約
- note整形
- PDF自動ダウンロード
- GUI

## セキュリティ・運用ルール

- chmod 777 を使用しない
- root 実行を前提にしない
- 必要最小限の権限で動作
- 元PDFを変更・削除しない
- 何のための処理かコメントを明記する
- 文系非エンジニア向けに分かりやすい構成にする

## 希望

- 必要ライブラリがある場合はインストール方法も提示
- 実行手順を段階的に説明
- まずは1PDFで検証
- 完成後は自己検証も行う
