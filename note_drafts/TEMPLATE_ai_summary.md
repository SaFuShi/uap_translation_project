## 編集ルール（全記事共通）

### 長さ・構成

- **目標行数：70〜90行**（免責事項含む）
- 長くなる場合は「主役となる現象」を1〜2個に絞って圧縮する
- Tape番号・文書内ページ番号・OCR技術説明は `AI解析メモ` の1行にまとめ、本文には出さない
- 引用は長くても2〜3文。全文引用より要約を優先する

### 言葉づかい・トーン

- 「UFO確定」「原因不明と断定」の印象を与えない
- 文書の種類を冒頭で明示する：「観測記録」「会話記録」「目撃証言フォーム」など
- 断定を避ける文体：「〜と記録されています」「〜と読み取れます」「〜と述べています」
- 「現象の正体は不明」と結論づけない。分からないことは「分からない」と書くにとどめる

### 自然説明の扱い

- 目撃者本人が「水ボイラーかも」「S-IVBかも」など自然な説明を口にしている場合は、それを優先して本文に入れる
- 説明がない場合は「記録には含まれていない」と書くにとどめる

### 誤解の先回り

- 読者が誤解しやすいポイントは `注意点` セクションで先に潰す
- チェックボックス矛盾・センサーモード・文書の性質・抜粋であること、など
- 「これは〇〇とは別のことです」という切り分けも有効

### 出典

- `元PDF：` の行は必ず入れる（URL形式）
- `Source URL：` は WAR.GOV のトップページ

## よくある問題と対処（チェックリスト）

記事を書き終えたら以下を確認する。

### 長さ
- [ ] 本文が90行を超えていないか
- [ ] Tape番号・文書内ページ番号を本文に書いていないか
- [ ] OCR処理の詳細説明が本文に入っていないか

### 断定・誇張
- [ ] 「UFOである」「原因不明である」と断定していないか
- [ ] 「直接的な証拠」「確定した」などの強い表現を使っていないか
- [ ] タイトルが現象を煽る表現になっていないか

### 誤解の先回り
- [ ] 文書の種類（抜粋・フォーム・会話記録）を明示しているか
- [ ] 目撃者自身の自然説明を記載したか（ある場合）
- [ ] チェックボックスの矛盾や曖昧なセンサーデータに注意書きを入れたか

### 出典
- [ ] `元PDF：` の行に完全なURLを入れたか
- [ ] ファイル名がURLに含まれているか
