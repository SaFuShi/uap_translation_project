## 1. v1 検証結果サマリー

### 1.1 PR061 実行結果（2026-06-27 実施）

```
入力: 96フレーム（3秒間隔）, 95ペア
設定: grid_size=32, residual_thresh=12.0（固定）, Phase Correlation

結果:
  LIGHTING_SHADOW_CHANGE: 95件（全ペア）
  その他全イベント      :  0件

Frame Delta v2 との比較:
  OBJECT_MOVE=93 → MI v1 = LSC=93
  DISAPPEAR=2   → MI v1 = LSC=2
```

**評価: v1 は部分的に成功。**
- ✅ OBJECT_MOVE=93 件が地形変化（LSC）と確認 → 人間確認結果の定量的裏付け
- ✅ Phase Correlation の bg=(0,0) → カメラ追跡補正が機能していた証拠
- ✅ bbox_ratio による広域 vs 局所の一次分類は正しく機能
- ❌ 固定閾値 12.0 が全セルを候補化 → 全 LSC になり UAP を検出できず
- ❌ 時間軸なし → 移動する UAP が単一ペアでは特定できなかった

### 1.2 v1 の根本的な制約の理解

PR061 の物理的構造（v1 検証で判明）:

```
3秒間の変化:
  地形パラックス残差: 20〜35 MAD（セル全体に分散）
  UAP 変化残差:     おそらく 35〜60 MAD（セルを完全離脱）

3秒間隔では:
  地形残差 > fixed_thresh=12.0 → 全セル候補化
  UAP残差 > 地形残差の可能性があるが、固定閾値では判別不能

結論: 固定閾値は無効。「その対のフレーム内での外れ値」を使う必要がある。
```

## 2. v2 設計判断サマリー

### 2.1 改善の核心: 適応的閾値

| 問題 | v1 対処 | v2 対処 |
|------|---------|---------|
| 全セル閾値超え | 固定 12.0 → 全候補 | p90（上位 10%）→ 常に 10% が候補 |
| UAP vs 地形の区別 | bbox_ratio のみ | bbox_ratio + 時間的一貫性 |
| 単一フレームペア | ペアごとの独立解析 | W=3 ペアのスライディング追跡 |

**なぜ p90 か:**
- 全有効セルの上位 10% が候補 → フレーム複雑さに関係なく常に「外れ値」を抽出
- 地形パラックス (20-35 MAD) の中で UAP セル (35-60 MAD) が p90 以上に入る可能性
- より保守的にしたい場合: p95（上位 5%）
- より感度を上げたい場合: p85（上位 15%）

### 2.2 時間的一貫性の導入理由

```
なぜ時間的一貫性が必要か:

単一ペアの問題:
  地形パラックス: 各フレームペアで高残差セルの位置が変わる（ランダムノイズ）
  UAP の移動:    同じ追跡対象が連続フレームで「近接した位置に」高残差を作る

追跡フィルタの効果:
  ランダムノイズ: W=3 ペアのうち 1 回しか同一位置に現れない → 却下
  UAP: W=3 ペアのうち 2〜3 回、近接位置に現れる → 持続候補

PR061 での期待:
  183s→189s（6秒・2ペア）: UAP が下方向に移動
  各 3秒ペアで UAP セルが 1〜2 セル下にずれる
  → 時空間クラスタリングで追跡可能
```

### 2.3 Targeted Frames の活用理由

| 比較項目 | Adaptive (3s) | Targeted (1s) |
|---------|--------------|--------------|
| 地形パラックス変化 | 大（全域で残差 20-35） | 小（推定 残差 8-15） |
| UAP 変位/フレーム | 51px（1.6 セル分） | 17px（0.5 セル分） |
| 時間ウィンドウ | 3ペア=9秒 | 5ペア=5秒 |
| UAP が同一セル内にいる時間 | <2 秒 | ~2 秒 |
| 検出信頼度 | 中（パラックスとの比較） | **高（短間隔で地形変化少）** |

特に Zone 3（180-198s）は 19 フレーム × 1秒間隔で UAP 出現〜フレームアウトをカバー。
→ v2 targeted モードが最も有効な検証対象。

## 3. アルゴリズム選択の根拠

### 3.1 適応的閾値: percentile vs z-score

| 方式 | メリット | デメリット |
|------|---------|----------|
| **percentile (採用)** | 分布形状に依存しない | 外れ値比率固定（常に 10%） |
| z-score (mean + 2σ) | 統計的根拠 | 正規分布を仮定、地形では歪みがある |
| IQR (中央値 ± 1.5IQR) | 外れ値に頑健 | パラメータ直感が難しい |

percentile の「常に 10% が候補」はデメリットにも見えるが、時間的一貫性でフィルタリングするため許容。

### 3.2 線形回帰 vs Kalman Filter

| 方式 | メリット | デメリット |
|------|---------|----------|
| **線形回帰 (採用)** | numpy のみで実装可 | 観測ノイズに弱い |
| Kalman Filter | 予測・平滑化が可能 | 実装複雑、scipy/pykalman 要 |
| 単純ドリフト計算 | 最も簡単 | 統計的信頼性なし |

v2 は numpy のみ（OpenCV なし）の制約を継続。線形回帰の R² で信頼度を評価する。

### 3.3 グリッドサイズ: adaptive=32 vs targeted=16

```
UAP の推定サイズ（人間確認より）:
  フレームアウト前の対象物: 視覚的に小さく見える飛翔体
  推定: 画面幅 1280px に対して 20〜60px 程度

32px グリッドでの検出:
  UAP が 32px セルを占有: 十分（UAP > 20px なら 1セル以上）

16px グリッドでの精度向上:
  UAP 位置の精度向上（16px → より細かく追跡）
  ただし処理時間 4 倍（セル数 4 倍）
  targeted frames の少ないセット（105 フレーム）なら許容範囲
```

### 4.3 信頼度の根拠

- **PTA (182→183s) 中**: UAP が frame_00182 では見えず、frame_00183 で右上に出現 → 高残差セルが右上に局所化すれば PTA

- **PTA (192→193s) 低**: マスク付近の再出現 → マスク境界ノイズと区別が困難

## 5. 成功基準

### 5.1 Adaptive Frames での成功基準

| 判定 | 条件 |
|------|------|
| **成功** | REVIEW_REQUIRED ≤ 5 AND pair_id 61-63 に ROM/PTA/PTD のいずれか |
| **部分成功** | LSC 件数が v1 の 95 件から 80 件未満に削減 AND 183s 区間が非 LSC |
| **失敗** | LSC=95 件維持（v1 と同結果） |

### 5.2 Targeted Frames での成功基準（主目標）

| 判定 | 条件 |
|------|------|
| **成功** | track_events.csv に LINEAR_MOTION トラックが存在 AND start_ts=182〜183s AND drift_y>0（下方向） AND R²≥0.5 |
| **部分成功** | POSSIBLE_TARGET_APPEAR が 182s〜184s のいずれかに存在 |
| **失敗** | 全ペアが LSC または REVIEW_REQUIRED |
