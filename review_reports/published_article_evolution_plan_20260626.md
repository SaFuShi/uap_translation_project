## 4. 公開済み記事修正ルール

### 4.1 修正実施の判断基準

公開済み記事（note.com）の修正は以下の条件をすべて満たす場合にのみ実施する:

| 条件 | 内容 |
|------|------|
| 視覚的事実の欠落 | VLM + 人間目視（信頼度≥0.8）で確認された視覚的事実が記事に未記載 |
| 元映像再確認 | 修正前に元映像の該当フレームを人間が再確認する |
| 慎重表現 | 修正候補文は断定表現を避け「とみられる」「確認できる」「推定」を使用 |
| 最小変更 | 修正は必要最小限の加筆に留め、既存記述の削除・書き換えは原則行わない |
| 追記明示 | note記事に「【追記】日付 + 修正理由の1文」を追加する |

### 4.2 修正禁止事項

- 物体の正体・種別の断定表現への変更
- 「確認できません」→「確認できます」への単純置換
- VLMのみの判定（人間確認なし）による修正
- 信頼度0.7未満の人間判定のみによる修正
- S_CLASS 記録への言及
- 外部API使用

### 4.3 修正フロー

```
1. 確認  : 元映像の該当フレームを人間が目視確認
2. 判断  : 修正基準（4.1）を満たすか確認
3. 草稿  : note_drafts を修正（慎重表現）
4. 確認  : 修正内容を review_reports に記録
5. 公開  : note.com を更新・再公開
6. 記録  : source_registry.csv の remarks に「修正日・修正内容」を追記
```

## 5. 詳細解析版での反映方針

### 5.1 詳細解析版の位置付け

概要版（現公開記事）はパイプライン自動解析による暫定整理である。
詳細解析版は以下を追加・深化させる次バージョンの記事とする。

| 項目 | 概要版 | 詳細解析版 |
|------|--------|----------|
| フレーム数 | 代表3〜5フレーム | 全フレーム or 重点フレーム |
| VLM解析 | なし / Phase 3 参照 | ローカルVLM全件評価結果を反映 |
| 人間目視 | 限定的 | ground_truth.csv の結果を反映 |
| 注意点精度 | 暫定 | Media Inspector 知見を反映 |
| 対象記述 | 代表フレームのみ | 複数フレームの変化を記述 |

### 5.2 Media Inspector の知見をコンテンツ化する方針

Media Inspector Phase 3（50枚評価）の結果は以下の形でコンテンツに接続する:

**A. 既存記事への「VLM解析メモ」追加**（詳細解析版）
> 「本映像は Media Inspector Phase 3（ローカルVLM Qwen2.5-VL-7B）による50フレーム評価対象となりました。VLMは全評価フレームで [対象物] を検出しました。人間目視確認と照合した結果、[比較結果] が確認されました。」

**B. 見落としフレームの可視化**（詳細解析版）
> 既知見落とし（E_known_miss_case）や Partial Match / Missed Secondary Objects は「VLMが検出したが当初の記事に未記載だった箇所」として明示する。

**C. 評価セット v2 への継承**
> ground_truth.csv のラベル訂正（label_error 6件）を manifest.csv v2 に反映し、次モデル比較（Qwen2.5-VL-32B 等）時の基準セットとして使用する。

**D. 実施しないこと**
- VLMの解析結果を根拠とした物体の同定・断定
- 外部APIを用いた追加解析
- S_CLASSへの言及
