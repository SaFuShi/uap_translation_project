## 共通修正候補（全20件）

### C-1：「軍用赤外線（IR）カメラ映像」→「IR映像とみられる映像」

**対象:** #071〜#090 全20件（本文1箇所ずつ）

**理由:** 「軍用」はファイル名・テキストから確認不可。FBI提出の映像だが、軍用機材かどうかは本文から断定できない。なお#067・#068は既にpublished済みで「軍用」表現あり。シリーズの一貫性を重視するか、v2ルール適用を優先するかは人間判断。

```
# 現行（全20件共通）
本フレームは1999年12月31日 HH:MM:SSのタイムスタンプを持つ軍用赤外線（IR）カメラ映像です。

# 修正候補
本フレームは1999年12月31日 HH:MM:SSのタイムスタンプを持つIR映像とみられる画像フレームです。
```

**判断ポイント:** #067・#068（published）との表現統一 vs v2ルール厳守。どちらを優先するか人間決定。

### #076（b8）— 中優先

**C-076-1：「IRカメラが別の追跡対象（暗点）に集中した可能性」**

```
# 現行（本文49行目付近）
ヘリコプター様機体が消失した後、IRカメラが別の追跡対象（この暗点）に集中した可能性を示すフレームです。
```
