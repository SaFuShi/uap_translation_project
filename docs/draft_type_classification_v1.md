# ドラフト生成 PDFタイプ分類仕様 v1

**適用開始:** #091以降
**作成日:** 2026-05-14
**目的:** トークンコスト削減 / provenance維持 / note投稿効率化

---

## 分類フロー

PDF取得 → タイプ判定 → 固定テンプレ適用 → Codexレビュー → MT/TXT生成

```
判定順:
1. テキスト層ゼロ + IR/EOカメラ映像 → TYPE-A
2. テキスト層ゼロ + 非カメラ画像    → TYPE-C
3. テキスト層あり・大部分リダクション → TYPE-B
4. FBI内部文書・断片/シリーズ構成   → TYPE-G
5. 外交電報（DOS/State Dept）       → TYPE-F
6. MISREP / 軍事インシデント報告書  → TYPE-D
7. 背景資料・調査報告・学術文書     → TYPE-E
```

---

### TYPE-A 禁止事項

- 「軍用赤外線（IR）カメラ映像」→ 「IR映像とみられる画像フレーム」
- 「追跡対象物」「飛行物体」「機体」「ロック」「捕捉」「EO/IR」
- 「移動していることが確認できます」→ 「別位置に確認できます」

### TYPE-B 禁止事項

---

## TYPE-C: 画像のみ（非カメラ映像）

**該当例:** 図版・図面・写真・図表のみのPDF
**特徴:** テキスト層ゼロ・IR/EOカメラ映像以外

### テンプレ

TYPE-Aテンプレに準じる。「画像タイプ」欄を「スキャン画像」に変更。カメラ映像固有の注意文（暗点・ズームイン・スケール目盛り）は省略。

### TYPE-G 禁止事項

- 「全N巻」「全Nページ」等シリーズ全体構成の断定
- Record Group・シリーズ番号の外部情報からの断定
- 捜査背景・事件背景の本文未確認断定

---

## 全TYPE共通禁止事項（draft_rules_v2 Rule 1〜7 準拠）

1. ファイル名由来以外の情報の事実断定
2. 外部背景・歴史情報の本文断定
3. 推定値への付記省略（必ず `（ファイル名より推定）` または `（本文確認不可）` を付記）
4. EO/IR断定語使用（追跡対象物・軍用IR・捕捉・EO/IR・機体・ロック等）
5. note投稿禁止形式（Markdownテーブル・引用ブロック・コードブロック・ネスト箇条書き）
6. シリーズ構成断定（全Nフレーム・時系列順N番目・ズームシリーズ・起点・最終フレーム）
7. source_registry未登録ファイル名の断定

---

## note投稿フォーマット禁止（全TYPE）

| 禁止 | 代替 |
|---|---|
| Markdownテーブル（\|---\|） | 箇条書き（- ） |
| 引用ブロック（>） | 【原文抜粋】ラベル＋通常テキスト |
| コードブロック（\`\`\`） | 削除または通常テキスト化 |
| ネスト箇条書き（- - ） | フラット箇条書き |

---

## 運用フロー（#091以降）

```
1. PDF取得 → タイプ判定（上記分類フロー）
2. source_registry に登録（filename / URL / hash）
3. 固定テンプレ適用 → ドラフト生成
4. Codexレビュー（BLOCK/WARN/PASS/UNVERIFIABLE）
5. BLOCK修正 → note_import_tests に MT/TXT 生成
6. note インポート → プレビュー確認（人間）
7. 公開 → source_registry に note_url / published_date 記録
```
