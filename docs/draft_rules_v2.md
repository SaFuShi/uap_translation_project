## Rule 1：OCR不可・準OCR不可記事の情報源制限

### 適用対象

テキスト抽出文字数が 0〜50文字程度の記事（スキャン画像PDF）。

### ルール

**ファイル名由来の情報だけを本文の事実として書く。**

ファイル名から読み取れる情報（日付・文書コード・件名・機関略称）は「ファイル名より」を付して記述可。
それ以外の情報（記述内容・背景事情・組織構造・歴史的文脈）は、本文から確認できない限り本文に書かない。

### NG例 / OK例

```
# NG（ファイル名以外の事実を断定）
本資料はNARAのRecord Group 342に分類された空軍関連文書である。

# OK（ファイル名由来に限定）
ファイル名「342_hs1-...」の「342」はNARA Record Group 342に対応する可能性があります
（ファイル名より推定。本文からは確認できません）。
```

```
# NG（テキスト抽出不可なのに内容を書く）
本資料にはUFO目撃の初動対応手順が記述されていると推測される。

# OK（ファイル名のみ根拠）
本資料の内容はテキスト抽出不可のため確認できません。
タイトル相当情報はファイル名から推定しています。
```

## Rule 2：Record Group・機関番号体系・歴史背景の断定禁止

### ルール

以下の情報は、記事本文（OCR抽出テキスト）から直接確認できない限り断定しない。

- NARAのRecord Group番号とその意味（例：「RG342は空軍」）
- FBI・CIA等の内部番号体系（例：「62-HQ-83894はFBI国内捜査番号」）
- 文書シリーズ構成（例：「Section 1・Section 2は同一事件のファイル」）
- 作成機関・署名者・担当部署
- 歴史的背景・政権・事件との関連

### 例外

- 文書内から OCR で直接読み取れた場合はその旨を明示して記述可
- 「ファイル名より」「OCR抽出テキスト〇文字より」等の provenance 明記が必須

## Rule 3：推定表現の書き方（必須フォーマット）

推定を書く場合は以下のいずれかの形式を使う。

```
（ファイル名より推定）
（本文からは確認できません）
〜の可能性があります（ファイル名より。本文確認不可）
〜と推定されます（根拠：ファイル名「xxx」）
```

### NG例

```
# NG（推定根拠なし）
本資料は1963年当時のケネディ政権下で作成されたと考えられる。

# OK（根拠明記）
「7.18.1963」はファイル名から1963年7月18日を示すと推定されます。
この時期はケネディ政権期にあたりますが、文書との関係は本文から確認できません。
```

## Rule 4：画像記事（テキストなしPDF）の表現基準

### 禁止表現・代替表現

| 禁止 | 代替 |
|------|------|
| 軍用赤外線（IR）カメラ映像 | IR映像とみられる映像（画像特性より） |
| 追跡対象物 | 暗点（または「追跡対象とみられる暗点」） |
| EO/IR（電気光学/赤外線センサー） | IR映像に類似した表示形式 |
| 照準オーバーレイと一致します | 照準オーバーレイに似た表示形式が見えます |
| IRカメラが捕捉した | 画像中央付近に確認できる |
| IRカメラが〜に集中した | 〜（画像内の暗点の位置変化より） |
| ローターブレードが確認できる | ローターブレード状の突起が見えるような形状 |
| 2種類の飛行物体が確認できます | 2つの異なる形状の対象が確認できます |
| 移動していることが確認できます | 前フレームと比較して別位置に確認できます |
| 継続的な捕捉は維持されています | 継続して画面内に確認されています |
| 追跡が継続されていることを示します | 暗点が継続して確認されています |

### 「軍用」「FBI提出」の扱い

- 「FBI提出」はsource_registryのAgency: FBIを根拠に記述可
- 「軍用」は本文・メタデータから確認できない場合は「IR映像とみられる」に留める
  - ただし #067/#068 は published 済みで「軍用」表現を使用しているため、シリーズ一貫性の観点から WARNレベルとする（BLOCKにはしない）

### 視覚的記述の限界を明示する

画像記事では以下の注意書きを必ず「注意点」セクションに含める：

```
本記事は視覚的観察に基づく記述であり、対象の性質・種別・挙動については判断しません。
センサー特性（IR映像のにじみ・アーティファクト）の影響を受けている可能性があります。
```

## Rule 5：note投稿向けフォーマット禁止事項（全記事）

以下は **全記事で禁止**（v1 では #055以降だったが、全記事に明示拡大）。

| 禁止 | 代替 |
|------|------|
| Markdown table（`\| col \|`形式） | 箇条書き or 【】ブロック形式 |
| 引用ブロック（`>`で始まる行） | 【原文抜粋】＋【要訳】形式 |
| 2階層以上のネスト箇条書き | フラット箇条書きに分解 |
| コードブロック（` ``` `） | 【抽出テキスト全文】プレーンテキスト形式 |

## チェックリスト（画像記事・OCR不可記事）

記事作成後に以下を確認する。

### 情報源
- [ ] 「軍用」を使っていないか（使う場合は根拠を明記）
- [ ] 「追跡対象物」ではなく「暗点」または「追跡対象とみられる暗点」を使っているか
- [ ] 「捕捉」「集中した」等のカメラの意図を示す表現を使っていないか
- [ ] ファイル名以外の情報を事実として書いていないか
- [ ] 推定表現に「ファイル名より」「本文確認不可」を付けているか

### 表現
- [ ] 「ローターブレードが確認できる」→「ローターブレード状の形状」に修正済みか
- [ ] 「〜が確認できます」が断定的すぎないか（フレーム間移動の「確認」は特に注意）
- [ ] 「EO/IR」「照準オーバーレイ」等の専門的断定がないか

### フォーマット
- [ ] Markdown table なし
- [ ] 引用ブロック（>）なし
- [ ] コードブロック（` ``` `）なし
- [ ] 連続空白行3行以上なし
