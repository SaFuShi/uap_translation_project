## Rule 1：OCR不可・準OCR不可記事の情報源制限

### 適用対象

テキスト抽出文字数が 0〜50文字程度の記事（スキャン画像PDF）。

### ルール

**ファイル名由来の情報だけを本文の事実として書く。**

ファイル名から読み取れる情報（日付・文書コード・件名・機関略称）は「ファイル名より」を付して記述可。
それ以外の情報（記述内容・背景事情・組織構造・歴史的文脈）は、本文から確認できない限り本文に書かない。

### NG例 / OK例

```
# NG（ファイル名以外の事実を断定）
本資料はNARAのRecord Group 342に分類された空軍関連文書である。

# OK（ファイル名由来に限定）
ファイル名「342_hs1-...」の「342」はNARA Record Group 342に対応する可能性があります
（ファイル名より推定。本文からは確認できません）。
```

```
# NG（テキスト抽出不可なのに内容を書く）
本資料にはUFO目撃の初動対応手順が記述されていると推測される。

# OK（ファイル名のみ根拠）
本資料の内容はテキスト抽出不可のため確認できません。
タイトル相当情報はファイル名から推定しています。
```

## Rule 2：Record Group・機関番号体系・歴史背景の断定禁止

### ルール

以下の情報は、記事本文（OCR抽出テキスト）から直接確認できない限り断定しない。

- NARAのRecord Group番号とその意味（例：「RG342は空軍」）
- FBI・CIA等の内部番号体系（例：「62-HQ-83894はFBI国内捜査番号」）
- 文書シリーズ構成（例：「Section 1・Section 2は同一事件のファイル」）
- 作成機関・署名者・担当部署
- 歴史的背景・政権・事件との関連

### 例外

- 文書内から OCR で直接読み取れた場合はその旨を明示して記述可
- 「ファイル名より」「OCR抽出テキスト〇文字より」等の provenance 明記が必須

## Rule 3：推定表現の書き方（必須フォーマット）

推定を書く場合は以下のいずれかの形式を使う。

```
（ファイル名より推定）
（本文からは確認できません）
〜の可能性があります（ファイル名より。本文確認不可）
〜と推定されます（根拠：ファイル名「xxx」）
```

### NG例

```
# NG（推定根拠なし）
本資料は1963年当時のケネディ政権下で作成されたと考えられる。

# OK（根拠明記）
「7.18.1963」はファイル名から1963年7月18日を示すと推定されます。
この時期はケネディ政権期にあたりますが、文書との関係は本文から確認できません。
```

## Rule 4：画像記事（テキストなしPDF）の表現基準

### 禁止表現・代替表現

| 禁止 | 代替 |
|------|------|
| 軍用赤外線（IR）カメラ映像 | IR映像とみられる映像（画像特性より） |
| 追跡対象物 | 暗点（または「追跡対象とみられる暗点」） |
| EO/IR（電気光学/赤外線センサー） | IR映像に類似した表示形式 |
| 照準オーバーレイと一致します | 照準オーバーレイに似た表示形式が見えます |
| IRカメラが捕捉した | 画像中央付近に確認できる |
| IRカメラが〜に集中した | 〜（画像内の暗点の位置変化より） |
| ローターブレードが確認できる | ローターブレード状の突起が見えるような形状 |
| 2種類の飛行物体が確認できます | 2つの異なる形状の対象が確認できます |
| 移動していることが確認できます | 前フレームと比較して別位置に確認できます |
| 継続的な捕捉は維持されています | 継続して画面内に確認されています |
| 追跡が継続されていることを示します | 暗点が継続して確認されています |

### 「軍用」「FBI提出」の扱い

- 「FBI提出」はsource_registryのAgency: FBIを根拠に記述可
- 「軍用」は本文・メタデータから確認できない場合は「IR映像とみられる」に留める
  - ただし #067/#068 は published 済みで「軍用」表現を使用しているため、シリーズ一貫性の観点から WARNレベルとする（BLOCKにはしない）

### 視覚的記述の限界を明示する

画像記事では以下の注意書きを必ず「注意点」セクションに含める：

```
本記事は視覚的観察に基づく記述であり、対象の性質・種別・挙動については判断しません。
センサー特性（IR映像のにじみ・アーティファクト）の影響を受けている可能性があります。
```

## Rule 7：Release 02 日本語読者向け反復補足ルール

Release 02 以降の記事ドラフト生成・既存記事修正では、Claude Code を含むすべての作成工程で以下を適用する。

### 単位換算

単位換算は「初出時だけ」ではなく、本文中に出てくるたびに原文単位へ日本向け換算を併記する。

- feet / フィート → メートルまたは km
- miles / マイル → キロメートル
- miles/sec / マイル毎秒 → km/秒
- miles/hour / マイル毎時 → km/h
- inches / インチ → cm
- pounds / ポンド → kg またはトン
- Fahrenheit / 華氏 → ℃
- AGL → 地表からの高さ

例：

- 10フィート（約3m）
- 700フィートAGL（地表から約213m）
- 8〜10マイル（約13〜16km）
- 秒速8〜14マイル（約13〜23km/秒）

同じ段落内で同じ単位表現が連続して何度も出る場合は、その段落の最初の1回に換算を付ければよい。記事全体で「初出に付けたから以後省略」は不可。

### 略語・組織名・機材名

英字略語・組織名・機材名も「初出時だけ」で終わらせず、読者が前へ戻らず読める頻度で日本語注釈を付ける。

対象例：

- AGL（地表からの高さ）
- FLIR（前方監視赤外線カメラ）
- NVG（暗視ゴーグル）
- JOC（合同作戦センター）
- OSI（空軍特別調査局）
- AFSWP（軍特殊兵器計画）
- AEC（米国原子力委員会）
- UNM（ニューメキシコ大学）
- NARA（米国国立公文書記録管理局）
- AFB（空軍基地）

同じ段落内で同じ略語が連続する場合は、最初の1回のみ注釈を付ければよい。注釈が長すぎる場合は、意味が伝わる範囲で短くする。

短縮例：

- AFSWP（軍特殊兵器計画）
- AEC（米国原子力委員会）
- OSI（空軍特別調査局）

## Rule 8：VID記事の文体・画像キャプション規則

Release 02 以降のVID（動画映像）記事に適用する。PR051（`ai_summary_DOW-UAP-PR051_Syrian_UAP_instant_acceleration_note_version.md`）を基準とする。

### 8-1. 本文の文体

本文は全体を通して**丁寧体（です・ます調）**を使用する。AI解析メモ・括弧内注釈も同様。

| NG（常体） | OK（丁寧体） |
|-----------|------------|
| 確認されない | 確認されていません |
| 確認されていない | 確認されていません |
| 確認できない | 確認できません |
| 示すものではない | 示すものではありません |
| を示す（文末） | を示しています |
| 扱わない | 扱いません |
| 消失している | 消失しています |
| 表示されている | 表示されています |
| 確認されるが | 確認されますが |
| 本フレームは〜から抽出。 | 本フレームは〜から抽出したものです。 |
| AAROの分析結論ではない | AAROの分析結論ではありません |
| 現象の正体を示すものではない | 現象の正体を示すものではありません |

### 8-2. 画像キャプション形式

VID記事の画像配置は以下の形式を使用する。

```
▼ 【画像①】{media_slug} 代表フレーム（{映像区分}・約{N}秒時点）
→ 使用ファイル：thumbnails/{media_slug}/frame_{秒数:04d}.png（note転記後にこの行を削除）

▲ {MP4ファイル名} より抽出（{タイムコード}）。{観察内容}。{留保事項}。
```

**各行の役割：**

| 行 | 役割 | note公開後の扱い |
|----|------|----------------|
| `▼ 【画像①】...` | 画像プレースホルダー（noteに画像をアップロード後に画像が入る） | 残す |
| `→ 使用ファイル：...` | 人間が転記時に参照するファイル名（作業メモ） | **削除する** |
| `▲ ...` | 公開キャプション（観察内容・留保事項） | 残す |

**キャプション（▲行）の記述順：**
1. 抽出元MP4ファイル名 + タイムコード
2. 映像種別（「通常表示映像から抽出」「処理版映像から抽出」等）
3. 観察内容（グレースケール・物体の状態・センサー表示等）
4. 留保事項（処理効果の可能性・断定の回避）

### 8-3. 使用ファイル明記ルール（→ 使用ファイル行）

```
→ 使用ファイル：thumbnails/{media_slug}/frame_{秒数:04d}.png（note転記後にこの行を削除）
```

- `→ 使用ファイル：` で始める
- ▼ヘッダー行の直後・空行の前に配置する
- 末尾に必ず「（note転記後にこの行を削除）」を付ける
- note.com への画像アップロード後、人間がこの行を削除してから公開する

### 8-4. 内部パスの公開禁止

以下のパスを公開確定テキスト（`→ 使用ファイル：` 行以外）に記載してはならない。

| 禁止パス | 代替表記 |
|---------|---------|
| `thumbnails/{slug}/frame_XXXX.png` | `{MP4ファイル名} より抽出（{タイムコード}・{映像区分}）` |
| `page_images/` | ページ番号 + 文書ファイル名 |
| `raw_media/` | ファイル名のみ |

**出典欄の正しい書き方（PR051基準）：**
```
- 掲載画像①出典：DOW-UAP-PR051_Syrian_UAP_instant_acceleration.mp4 より抽出（00:05・通常表示映像）
- 掲載画像②出典：DOW-UAP-PR051_Syrian_UAP_instant_acceleration.mp4 より抽出（04:30・処理版・加工済み）
```

**避けるべき書き方（PR050 出典欄の既存表記。同記事は公開済みのため変更不可）：**
```
- 代表フレーム：thumbnails/DOW-UAP-PR050/frame_0000.png（約0秒時点）
```

### 8-6. 「元映像」「原本映像」「処理前映像」の使用禁止

VID記事では以下の表現を使用しない。

| 禁止表現 | 代替表現 |
|---------|---------|
| 元映像 | 通常表示映像 |
| 原本映像 | 通常表示映像 |
| オリジナル映像 | 通常表示映像 |
| 処理前映像 | 通常表示映像 |
| 処理前の映像 | 通常表示映像 |

**禁止理由：** AAROは映像が機密ネットワークへのアップロード前にデジタル改変済みであると明記している。「元映像」「原本映像」等の表現は未改変の原本が存在することを示唆するが、改変前の状態は確認できない。

**「通常表示映像」の意味：** 公開動画内のセグメント区分（スロー再生版・強調処理版・白黒反転版ではない部分）を示す。原本性の断定を含まない。

**フレームが通常表示映像（非処理版）からの抽出であることを示す推奨表現：**

```
本フレームは、公開動画の内、スロー再生版や強調処理版ではない通常表示映像から抽出したものです。
```

タイムライン・出典・要点セクションの区分ラベルも「（通常表示映像）」「（通常表示映像フル尺）」「（通常表示映像リプレイ）」等に統一する。

## Rule 10：標準免責文テンプレート

記事末尾の免責文は以下の標準形を使用する。

### 共通原則

- 基本主体は「war.gov で公開された米政府資料」とする。AARO を固定主語にしない。
- AARO が本文中に登場する記事では、本文の初出に `AARO（全領域異常解決局／米国防総省のUAP調査組織）` を付ける。
- 免責文自体に AARO を記載する場合も同様に補足を付ける（補足なしの `AARO` は `rule_candidate_scan.py` CAT-01 で検出される）。
- 「UAP の正体・起源を断定するものではありません」という留保を全記事に含める。

### PDF / DOC 型記事（AARO 公開資料）

AARO が公開主体の資料（ODNI-UAP-D001 等）に使用する：

```
本記事はAAROおよびwar.govが公開した米政府の公式資料を、Claude Code・ChatGPT・CodexおよびローカルAI処理環境を用いて翻訳・要約したものです。AARO（全領域異常解決局／米国防総省のUAP調査組織）はこれらの資料の公開・管理主体として本文中に記述されています。UAP（未確認異常現象）の正体・起源についての断定は含みません。AI処理には誤変換・誤訳が含まれる可能性があります。公式見解は各機関の原文資料をご参照ください。元資料のリンクを各記事末尾に掲載しています。投稿者は米政府・AARO・各機関とは無関係です。
```

### PDF / DOC 型記事（非 AARO 公開資料）

AARO が本文に登場しない資料（CIA・DIA 等）に使用する：

```
本記事はwar.govが公開した米政府の公式資料を、Claude Code・ChatGPT・CodexおよびローカルAI処理環境を用いて翻訳・要約したものです。UAP（未確認異常現象）の正体・起源についての断定は含みません。AI処理には誤変換・誤訳が含まれる可能性があります。公式見解は各機関の原文資料をご参照ください。元資料のリンクを各記事末尾に掲載しています。投稿者は米政府・各機関とは無関係です。
```

### VID 型記事（PR050/PR051 基準）

```
※ 本記事はAI映像解析・ffprobe技術情報・フレーム目視確認を用いた「AI概要版」です。
```

本文末尾の留保文：

```
本記事は視覚的観察に基づく記述であり、対象の性質・種別・挙動については判断しません。
センサー特性（IR映像のにじみ・アーティファクト）の影響を受けている可能性があります。
```

### IMG 型記事（一般・OCR不可スキャン PDF 等）

```
※ 本記事は AI 画像解析・一次資料記述を用いた「AI概要版」です。
テキスト情報は存在せず、記事内容は画像の視覚的情報に基づく記述です。
原文リンクを重視し、可能な限り一次ソースを確認できる形で整理しています。
```

### IMG 型記事（FBI系画像資料・デジタルレンダリング等）

FBI提出画像・デジタルレンダリング等に使用する（Release 03 Western US Event Digital Rendering 等）。

**方針:**

- war.gov を公開主体とし、FBI を不要に主語化しない。
- FBI は「メタデータに記録されている提出機関」として言及する。
- UAP の正体・起源を断定しない留保を含める。
- FBI（連邦捜査局）の初出に補足を付ける（`rule_candidate_scan.py` CAT-01 対応）。

本文末尾の免責文：

```
本記事はwar.govが公開した米政府の公式画像資料を、AI画像解析・一次資料記述を用いて整理したものです。UAP（未確認異常現象）の正体・起源についての断定は含みません。記事内容は画像の視覚的情報に基づく記述です。本資料はFBI（連邦捜査局）提出資料としてメタデータに記録されています。公式見解は各機関の原文資料をご参照ください。元資料のリンクを各記事末尾に掲載しています。投稿者は米政府・各機関とは無関係です。
```

本文内の留保文（注意点セクション等に含める）：

```
本記事は視覚的観察に基づく記述であり、対象の性質・種別・挙動については判断しません。
本画像はデジタルレンダリングまたは加工済み画像の可能性があり、撮影機材・撮影条件の詳細は資料内に確認できません。
```

### AUD 型記事

PDF / DOC / VID / IMG 型は定義済み。AUD 型は未定義。AUD 型記事が新設される際にこのセクションに追加する。

- [ ] 「軍用」を使っていないか（使う場合は根拠を明記）

- [ ] コードブロック（` ``` `）なし
- [ ] 連続空白行3行以上なし
