## 1. 読者導線と表現スタンス

### 1-1. 本プロジェクトにおける UAP の定義

本プロジェクトは米政府公開資料（war.gov/UFO）に基づき、資料を「UAP（未確認異常現象）関連資料」として扱う。

> **UAP（Unidentified Anomalous Phenomena）とは、現時点で正体が特定されていない現象・物体のことであり、地球外生命体や特定の存在・技術を示すものではない。**

一般には「UFO映像」「UFO資料」として関心を持たれやすい資料であるが、記事・要訳・見出しにおいて「UFO」を使う場合は読者の理解補助目的に限定し、常に「UAP」を主表記とする。

### 1-2. 表記優先順位

| 表現したいもの | 推奨表記 | 許容表記 | 禁止表記 |
|-------------|---------|---------|---------|
| 未確認の空中現象 | UAP | UAP（UFOとも）| UFO単独・宇宙人・エイリアン |
| 確認できる物体 | 「領域内の物体」「点状の光」等の視覚観察表現 | — | 「UFO」「未確認飛行物体」を断定的に使用 |
| 現象の性質 | 「現時点で未確認」 | — | 「地球外由来」「人工衛星でない」等の断定 |

### 1-3. 読者への説明文（記事リード文に使用可）

> 本資料は米国防省が war.gov/UFO を通じて公開した UAP（未確認異常現象）関連資料です。ここでいう UAP は「現時点で正体が確認されていない現象」を指し、特定の存在や技術を示すものではありません。

## 5. PDF 処理ルール（Release 01 からの更新点）

### 5-1. 基本フロー

```
PDF取得 → ocr_status 確認 → タイプ分類（draft_type_classification_v1.md）
→ content_category 確認 → テンプレ選択 → ドラフト生成 → Codex レビュー
```

### 5-2. Release 02 PDF の特記事項

- **DOW-UAP-D017:** 軍関連書簡。`historical_record` または `administrative`
- **CIA-UAP-D001:** 1973年ソ連向け情報報告書。`historical_record`。CIA 文書特有の記述形式に注意
- **ODNI-UAP-D001:** USPER（米国人関与案件）文書。センシティブな記述が含まれる可能性あり。断定禁止を特に厳守
- **DOE-UAP-D001〜D003:** エネルギー省関連。核施設（PANTEX）・ロスアラモス国立研究所関連の可能性あり。施設名・人名の扱いは `draft_rules_v2.md` Rule 2 に従う

### 5-3. ocr_status による処理分岐

| ocr_status 値 | 意味 | 処理 |
|-------------|------|------|
| `not_needed` | テキスト層あり | OCR 不要。テキスト直接抽出 |
| `needed` | テキスト層なし（スキャン）| OCR 実施後に処理。未実施の場合はファイル名由来情報のみ |
| `partial` | 一部テキスト層あり | 抽出済み部分のみ事実化。残部は「確認不可」と明記 |
| `pending` | 未確認 | 処理前に確認必須 |

### 5-4. OCR不可原因分類と再解析チャレンジ

OCR不可ファイルを単に保留にせず、**なぜ読めないのかを分類し、再解析可能性を判断する**。

#### 5-4-0. パイプライン分岐設計

OCR状態に基づき、PDFは**通常ライン**と**OCR Challenge Pipeline**の2系統に分岐する。

```
【通常ライン】
PDF
 └─ ocr_status: not_needed / partial
      ↓
    text_layer / OCR
      ↓
    translation
      ↓
    summary
      ↓
    note draft

【OCR Challenge Pipeline】
PDF
 └─ ocr_status: needed（かつOCR失敗・テキスト取得不可）
      ↓
    ocr_failure_reason 分類（5-4-1）
      ↓
    画像品質診断（image_quality / text_visibility 評価）
      ↓
    補正候補判定（recommended_next_step 決定）
      ↓
    ┌─ retry_ocr_*（解像度・コントラスト・傾き補正後に再OCR）
    ├─ ai_vision_review（AI Vision モデルで画像読み取り）
    └─ human_visual_review（人間が目視確認）
      ↓
    記事化可否判断
    ├─ 可: 通常ラインの translation 以降へ合流
    └─ 不可: hold_no_article（保留）→ ocr_challenge_log.csv に記録
```

**分岐の判定基準:**

| 条件 | 分岐先 |
|------|--------|
| `ocr_status = not_needed` または `partial`（テキスト抽出済み）| 通常ライン |
| `ocr_status = needed` かつ OCR 実行で十分なテキスト取得済み | 通常ライン |
| `ocr_status = needed` かつ OCR 失敗・テキスト取得不可 | OCR Challenge Pipeline |
| `ocr_status = pending` | 確認後に判定 |

**重要原則:** OCR Challenge Pipeline を経た結果（AI Vision・目視）は、通常ライン由来のテキストと**同等には扱わない**。記事内で情報源の種別（OCR / AI Vision / 目視）を必ず明記する。

#### 5-4-1. ocr_failure_reason 分類一覧

| 分類値 | 意味 | 典型的な症状 |
|-------|------|------------|
| `handwriting` | 手書き文字が多く、通常 OCR で読めない | 手書きメモ・署名・注釈が主体 |
| `low_resolution` | 解像度が低く文字が潰れている | ファックス送信物・複数世代コピー |
| `poor_contrast` | 背景と文字のコントラストが低い | 薄い印字・紙の劣化・裏写り |
| `skew_or_rotation` | 傾き・回転・スキャン歪みがある | 斜め読み込み・製本綴じ部の歪み |
| `redacted_or_cropped` | 黒塗り・切れ・欠損で本文が読めない | 機密解除前の墨塗り・ページ端欠損 |
| `image_only_non_text` | 写真・図版中心で文字資料ではない | IR フレーム・航空写真・地図 |
| `unknown_file_structure` | ファイル構造や中身が不明、解析方法の判定が必要 | 異常な PDF 構造・埋め込み形式不明 |
| `corrupted_or_unreadable` | ファイル破損または読み込み不能 | 開けない・中身が空・バイナリ異常 |

#### 5-4-2. 再解析記録フォーマット

OCR不可ページは以下の項目を記録する。将来的には `metadata/ocr_challenge_log.csv` に集約する。

| フィールド | 説明 | 例 |
|----------|------|----|
| `file_name` | 対象ファイル名 | `CIA-UAP-D001_...pdf` |
| `page_number` | 対象ページ番号（0始まり）| `0`, `1`, `all` |
| `ocr_failure_reason` | 上記分類値（複数可、セミコロン区切り）| `poor_contrast; skew_or_rotation` |
| `image_quality` | 画質の総合評価 | `poor` / `fair` / `good` |
| `text_visibility` | 文字の目視判読可否 | `none` / `partial` / `most` / `full` |
| `recommended_next_step` | 推奨する次のアクション（下記参照）| `retry_ocr_after_deskew` |
| `human_review_needed` | 人間による目視確認が必要か | `true` / `false` |
| `notes` | 補足メモ（自由記述）| 「2ページのみ墨塗りなし」等 |

#### 5-4-3. recommended_next_step 一覧

| 値 | 意味 |
|----|------|
| `retry_ocr_high_resolution` | 高解像度スキャン・アップスケール後に OCR 再試行 |
| `retry_ocr_after_contrast_adjustment` | コントラスト・輝度補正後に OCR 再試行 |
| `retry_ocr_after_deskew` | 傾き補正・回転補正後に OCR 再試行 |
| `ai_vision_review` | AI Vision モデルによる画像読み取りを試みる |
| `human_visual_review` | 人間が目視で確認する（AI では判断不可）|
| `hold_no_article` | 現時点では記事化せず保留 |

#### 5-4-4. 結果記録のルール

再解析を実施した場合、以下の3つを**必ず分けて記録する**。

1. **OCR 結果:** 自動抽出されたテキスト（未補正のまま）
2. **目視結果:** 人間または AI Vision が確認した内容（確認者・日付を付記）
3. **推定:** 文脈・前後関係から推測した内容（「推定」と明示）

> **絶対禁止:** 読めない文字を推測で補って、推定・目視・OCR 結果を混在させた状態で本文に記載すること。

## 6. 動画（VID）処理ルール

### 6-1. 基本前提

- VID ファイルの実体は `.mp4`（DVIDS 経由でダウンロード済み）
- ファイル名は `make_safe_filename(title)` により生成（PR050〜PR099 形式）
- 出典確認は `dvids_video_id` の値を用いて DVIDS ページで行う

### 6-2. 視覚観察ルール

動画から記事にできる「事実」は以下に限定する。

**記述可能（視覚観察）:**
- 画面内に存在する光点・形状・色の記述（「画面上部に白い光点が確認できる」）
- センサー表示情報（タイムスタンプ・コールサイン・画面テキスト）
- 動きの記述（「光点が左から右へ移動する」「フレーム外へ消える」）
- センサー種別の明示（IR / FMV / EO と記載がある場合はそのまま記述）

**記述禁止（断定・解釈）:**

| 禁止表現 | 理由 | 代替表現 |
|---------|------|---------|
| 「UAP が加速した」 | 加速を断定 | 「光点の移動速度が変化しているように見える」 |
| 「センサーがロックした」 | センサー動作を断定 | 「センサーが物体を中心付近に維持している」 |
| 「UFO が追跡された」 | UFO 断定＋意図断定 | 「光点が継続的に画面内に映されている」 |
| 「急加速を確認」 | 速度を断定 | 「映像内で物体の位置が急激に変化している」 |
| 「回避行動」 | 意図を断定 | 「物体の軌跡が変化している」 |
| 「地球外技術」 | 出自を断定 | 記述不可 |

### 6-3. IR / FMV 映像の扱い

- IR（赤外線）映像では白黒反転・熱源ノイズが発生する。「白く光る = 高温」は推定であり断定しない
- FMV（フルモーションビデオ）映像は可視光カメラ。IR との混同禁止
- センサー種別が不明な場合は「映像種別不明」と明記する

### 6-4. タイムスタンプ管理

- 動画内タイムスタンプ（`00:00`形式）と実際の観測時刻（Z時刻）を混同しない
- 記事内でタイムスタンプを引用する場合は「動画内 `00:15` 時点」と明記する

### 6-5. 代表フレーム抽出（将来実装向け）

- **現時点では実装しない**（サムネイル抽出・フレーム解析は本方針書のスコープ外）
- 将来実装する場合は：抽出フレームのタイムスタンプ・抽出ツール・ソースファイルを記録する

### 6-6. 動画単体記事化の条件

以下をすべて満たす場合に単体記事化可能とする。

1. `dvids_video_id` が存在し、DVIDS ページで出典確認できる
2. ファイル名または DVIDS タイトルから `incident_date` または `incident_location` が特定できる
3. 視覚観察として記述できる内容が1項目以上存在する
4. 断定表現を使わずに記事が成立する

## 7. 音声（AUD）処理ルール

### 7-1. 基本前提

- AUD ファイルの実体は `.mp4`（音声トラック付き動画コンテナ）
- ファイル名に「Audio」「Debriefing」「Excerpt」等が含まれる場合も同様
- Release 02 の AUD 7件は全て NASA 宇宙飛行士関連音声（Apollo / Mercury シリーズ）

### 7-2. 文字起こしフロー（将来実装向け）

```
AUD (.mp4) → Whisper等での文字起こし → 英文確認 → 日本語訳 → 記事化
```

**現時点では Whisper 実装を行わない。** 文字起こし未実施の場合はファイル名由来情報のみ事実化。

### 7-3. 文字起こし実施時のルール

- **英文確認:** 文字起こしテキストは必ず人間が英文として確認する。AI 出力をそのまま記事に使用しない
- **transcript confidence の扱い:**
  - 明瞭に聞き取れる部分のみ引用可
  - 不明瞭・推測が必要な箇所は `[不明瞭]` または `[inaudible]` と記載
  - AI の「補完」による推定テキストは引用禁止（hallucination リスク）
- **日本語訳:** 直訳を基本とし、補足解説は明示的に分離する

### 7-4. NASA 音声資料の扱い

- Apollo・Mercury 等の歴史的音声は `audio_record` + `historical_record` として扱う
- **「UFO目撃証言」として提示しない**
- 宇宙飛行士の発言が UAP に関連する可能性がある場合も、発言内容の事実と解釈を分離する
  - OK: 「宇宙飛行士が『光る物体がある』と発言している」
  - NG: 「宇宙飛行士が UFO を目撃したと証言している」

### 7-5. 音声不明瞭時の扱い

| 状況 | 対応 |
|------|------|
| 音声全体が不明瞭 | ファイル名由来情報のみ記載。「音声内容は確認不可」と明記 |
| 一部不明瞭 | 明瞭部分のみ引用。不明瞭箇所は `[inaudible]` |
| 背景雑音・送受信ノイズ | ノイズを特定の意味に解釈しない |

## 8. 画像（IMG）処理ルール

### 8-1. 基本前提

- IMG ファイルは `.png` または `.jpg`
- Release 01 の IMG: FBI フォト（a1〜a8）・NASA アポロ写真（vm1〜vm6）
- Release 02 での IMG 追加がある場合は同方針を適用する

### 8-2. 視覚観察の範囲

画像から記述できる「事実」は以下に限定する。

**記述可能:**
- 画面内に存在する形状・色・明暗の記述（「円形の明るい物体が確認できる」）
- 画像内テキスト（キャプション・座標・日時表示）
- 画像の種類（航空写真・赤外線・可視光）がメタデータ等で確認できる場合

**記述禁止:**

| 禁止表現 | 理由 | 代替表現 |
|---------|------|---------|
| 「UAP が映っている」 | 物体確定を断定 | 「円形の光点が確認できる」 |
| 「移動している物体」 | 静止画での動きを断定 | 「画像内に確認される物体」 |
| 「対象物を捕捉」 | 意図・追跡を断定 | 「画像内に映された物体」 |
| 「不自然な形状」 | 主観的断定 | 具体的な形状の記述（「楕円形」「不規則な輪郭」等）|

### 8-3. IR 画像の扱い

- FBI フォト（スキャン IR フレーム）: 熱源ノイズ・コントラストの解釈禁止
- NASA アポロ写真: 光学ノイズ・反射光・レンズフレアの可能性を除外しない
- 「白く光る = 高温」「暗い = 低温」等の温度断定禁止

### 8-4. フレーム比較の扱い

- 複数フレームの比較から「移動」「変形」等を断定しない
- 比較が必要な場合は「2枚の画像において物体の位置が異なっている」と記述する

### 8-5. サムネイル利用ルール

- note 記事のサムネイルに IMG ファイルを使用する場合は出典（war.gov/UFO）を記事内に明記する
- クロップ・加工を行った場合は加工の内容を記録する（将来の監査対応）
- **センセーショナルな見せ方を避ける:** 「UFO 写真」「決定的証拠」等の表現を使用しない

## 9. note 記事化ルール（メディアタイプ別）

### 9-1. 共通ルール

`draft_rules_v2.md` の全ルールに加え、以下を追加適用する。

- 記事冒頭に **ソースメディアの種別**（動画 / 音声 / 画像 / 文書）を明記する
- `dvids_video_id` がある場合は DVIDS URL を出典として記載する（war.gov URL との併記）
- `note_series` の値に従い、連載シリーズの通し番号を記事タイトルに反映する

### 9-2. VID 記事のテンプレ構成

```
# [機関] [PR番号]──[視覚観察による短い描写]・[年]【米政府公開動画 #NNN】

---

## 動画メタデータ

- File Name: [filename].mp4
- Incident Date: [日付]
- Incident Location: [場所]
- Source（war.gov）: https://www.war.gov/UFO/
- Source（DVIDS）: https://www.dvidshub.net/video/[dvids_id]

## 視覚観察記録

[タイムスタンプ付きの視覚観察のみ。断定禁止]

## 補足情報

[ファイル名・DVIDS タイトルから確認できる情報のみ。推定は明記]
```

## 10. 禁止表現一覧

### 10-1. 断定禁止（全メディアタイプ共通）

| 禁止表現 | 代替表現 |
|---------|---------|
| UFO（単独で断定的に使用）| UAP |
| 宇宙人・エイリアン・地球外生命体 | 記述不可 |
| 地球外由来・人工物でない | 記述不可 |
| 証拠・決定的証拠 | 「資料」「映像」「記録」 |
| 未知の飛行体 | 「現時点で未確認の飛行現象」 |

### 10-2. 動画・音声固有の禁止表現

| 禁止表現 | 代替表現 |
|---------|---------|
| 急加速・急上昇 | 「映像内で物体の位置が急激に変化している」 |
| ロック・捕捉（センサー） | 「センサーが物体を映し続けている」 |
| 追跡 | 「物体が継続的に映されている」 |
| 回避行動 | 「物体の軌跡が変化している」 |
| UFO証言 | 「発言内容」 |

### 10-3. 画像固有の禁止表現

| 禁止表現 | 代替表現 |
|---------|---------|
| 移動している物体 | 「画像内に確認される物体」 |
| 不自然な形状 | 具体的な形状の記述 |
| 対象物を捕捉 | 「画像内に映された物体」 |

## 11. Codex 監査向け追加チェック項目

`audit_checklist_v1.md` の既存チェックに加え、以下を Release 02 以降に追加する。

### M1. 動画記事の断定表現チェック

| チェック項目 | 判定基準 |
|------------|---------|
| 「急加速」「ロック」「追跡」「回避行動」が断定的に使われていないか | 断定 → 🔴 BLOCK |
| 視覚観察と解釈（対象物の性質）が混在していないか | 混在 → 🔴 BLOCK |
| IR / FMV の種別が明記されているか（判明している場合）| 未明記 → ⚠️ WARN |
| タイムスタンプが「動画内 XX:XX 時点」形式で記述されているか | 不正形式 → ⚠️ WARN |

### M2. 音声記事の誤認チェック

| チェック項目 | 判定基準 |
|------------|---------|
| 文字起こしが未実施の場合、「文字起こし未実施」と明記されているか | 未明記 → 🔴 BLOCK |
| `[inaudible]` を使わずに不明瞭部分を補完していないか | AI 補完テキスト混入 → 🔴 BLOCK |
| 「UFO 証言」「目撃証言」として提示していないか | 提示あり → 🔴 BLOCK |
| 宇宙飛行士発言が発言事実と解釈に分離されているか | 未分離 → ⚠️ WARN |

### M3. 画像記事の視覚観察と解釈の混在チェック

| チェック項目 | 判定基準 |
|------------|---------|
| 「移動」「回避」等の動的断定が含まれていないか | 含まれる → 🔴 BLOCK |
| IR 画像で熱源断定をしていないか | 断定あり → 🔴 BLOCK |
| 複数画像比較から性質断定をしていないか | 断定あり → 🔴 BLOCK |

### M4. サムネイル・出典チェック

| チェック項目 | 判定基準 |
|------------|---------|
| サムネイルに使用した画像の出典が記事内に明記されているか | 未明記 → ⚠️ WARN |
| サムネイルキャプションに断定表現が含まれていないか | 含まれる → 🔴 BLOCK |

### M5. DVIDS / war.gov URL 整合性チェック

| チェック項目 | 判定基準 |
|------------|---------|
| `dvids_video_id` がある場合、DVIDS URL が記事に含まれているか | 未含 → ⚠️ WARN |
| war.gov URL が正しいか（`https://www.war.gov/UFO/`）| 不正 URL → 🔴 BLOCK |
| DVIDS URL の ID が `files_catalog.csv` の `dvids_video_id` と一致するか | 不一致 → 🔴 BLOCK |

### M6. AI Hallucination リスクチェック

| チェック項目 | 判定基準 |
|------------|---------|
| 動画・音声の内容が「視聴・聴取」ではなく「ファイル名・タイトルから推測」の場合、その旨が明記されているか | 未明記 → 🔴 BLOCK |
| 文字起こし未実施なのに発言内容を記述していないか | 記述あり → 🔴 BLOCK |
| `source_registry.csv` に未登録の情報を事実として記述していないか | 記述あり → 🔴 BLOCK |
| AI が生成した補足情報（背景・組織説明等）がソース確認なく混入していないか | 混入 → 🔴 BLOCK |
