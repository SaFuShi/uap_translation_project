## 1.1 語尾統一ルール（です・ます調）

記事本文中の述語はすべて**です・ます調**で統一します。以下の置換が必須です。

| ❌ 使用禁止（普通体） | ✅ 正しい形（です・ます調） |
|---|---|
| `内容は本記事では扱わない` | `内容は本記事では扱いません` |
| `確認できない` | `確認できません` |
| `特定できない` | `特定できません` |
| `断定できない` | `断定できません` |
| `示すものではない` | `示すものではありません` |
| `確認されていない` | `確認されていません` |
| `〜が伴っている` | `〜が伴っています` |
| `〜が広がっている` | `〜が広がっています` |
| `〜と推定される` | `〜と推定されます` |
| `〜と推定されるが確認できない` | `〜と推定されますが確認できません` |

**適用範囲：** 記事本文・▲キャプション・要点・AI読解・注意点・ディスクレイマーのすべて。  
**除外：** AI解析メモ（箇条書き形式）・メタデータフィールド値・外部引用文。

## 1.2 「確認できません」と「断定できません」の使い分け（v2新規）

本テンプレートでは、不確実性の種別によって2つの否定表現を使い分けます。

### 確認できません（視覚的・物理的な確認の限界）

**使用条件：** 映像フレームから目視・識別・読み取ることができない場合。観察の物理的限界。

```
（例）
× IRセンサーと推定されるが断定できません → ✅ IRセンサーと推定されますが確認できません
× UAP対象物は明確に断定できませんでした → ✅ UAP対象物は明確に確認できませんでした
○ センサー種別を示すフレーム内テキストは確認されていません
○ 地名・タイムスタンプ等の文字情報は確認されていません
```

### 断定できません（判断・推論の限界）

**使用条件：** 情報はあるが十分な証拠がなく、断定する根拠がない場合。可能性を排除しない文脈。

```
（例）
× IRセンサーとは確認できません → ✅ IRセンサーと推定されますが断定できません
× 自然現象かどうか確認できません → ✅ 自然現象か否か本映像単体では断定できません
○ 物体の正体・性質を本記事では断定しません
○ 撮影機材・プラットフォームは本映像単体では断定できません
```

### 判断フロー

```
映像を見て…
  ├─ 「フレームを見ても読み取れない・見えない」     → 確認できません
  └─ 「見えるが何かは分からない・確証がない」       → 断定できません
```

## 3. セクション別規則

### 3.1 タイトル

| 要素 | 規則 | 例 |
|---|---|---|
| 記事ID | `#2_XXX` 形式（`#R02-XXX` は**不可**） | `#2_010` |
| 冒頭 | `【概要版#2_XXX】DoW DOW-UAP-PRXXX：` で固定 | `【概要版#2_008】DoW DOW-UAP-PR050：` |
| 視覚的説明 | 映像フレームから確認できる最も顕著な要素 | `複数の白い物体と線状痕跡が映る映像（IR映像と推定）` |
| ファイル名情報 | `──ファイル名より：[内容]──` で区切る | `──ファイル名より：イラン上空・4機UAP編隊・2022年8月26日──` |
| 末尾 | `[地域]・[日時]・米国防省公開・Release 02` で終わる | |

**必須（全件）：**
```

### 3.4 画像プレースホルダーと▲キャプション（v2更新）

```
▼ 【画像】DOW-UAP-PRXXX 代表フレーム（映像開始直後・約0秒時点）

```

**▲キャプション語尾ルール（v2新規）：**

▲キャプション行はすべて**です・ます調**で記述します。

| ❌ 不可（普通体） | ✅ 正しい形（です・ます調） |
|---|---|
| `〜が確認できる。` | `〜が確認できます。` |
| `〜とみられる対象が確認できる。` | `〜とみられる対象が確認できます。` |
| `〜が広がっている。` | `〜が広がっています。` |

- `掲載画像：` 行は note 転記後に削除する（PR051の `→ 使用ファイル：` と同等）
- note では画像ブロックとして `▼/▲` を挟んで挿入する
- アイキャッチ推奨フレームは原則 `frame_0005.png`。短尺映像（5秒以下）の場合は `frame_0000.png` でも可

### 3.6 映像メタデータ（ffprobe）

**拡張箇条書き形式（必須）：**
```
ffprobeによる技術情報を以下に示します。

- コンテナ：MP4
- 映像コーデック：H.264 / AVC（High Profile）
- 解像度：1920×1080（FHD・アスペクト比 16:9）
- フレームレート：30fps
- 再生時間：5.4秒（約5秒）
- 音声コーデック：AAC 48kHz ステレオ（音声内容は本記事では確認対象外）
- ...
```

**パイプ区切り単行形式は使用しない（旧形式）：**
```
❌ - コンテナ：MP4 | 解像度：1920×1080 | ...
```

### 3.7 AI解析メモのタイムコード記録（v2更新）

**フレーム数ではなくタイムコード列挙を使用します。**

```
（v2標準形式）
✅ 映像フレーム目視確認済み（00:00・00:05・00:10）

（旧形式 — 使用不可）
❌ 映像フレーム目視確認済み（3フレーム）
```

- タイムコードは `MM:SS` 形式（例：`01:30` = 1分30秒）
- サムネイルフレームの命名規則：`frame_NNNN.png`（NNNN は秒数、ゼロパディング）
  - `frame_0000.png` → `00:00`
  - `frame_0005.png` → `00:05`
  - `frame_0060.png` → `01:00`
- `apply_article_template.py v2`（T16）がサムネイルファイルから自動生成します

### 3.8 「注意点」セクション（必須）

全記事に `## 注意点` セクションを設置すること。最低限以下の4項目を含む：

1. **物体の正体・種別について** — UAPはファイル名由来の名称であり断定しない
2. **ファイル名情報の位置付けについて** — ファイル名要素は映像フレーム内未確認
3. **IR映像の判断について** — 推定に留め、確認できないことを明示
4. **映像の撮影状況・プラットフォームについて** — 撮影情報未確認・コールサイン黒塗り

## 4. Article Factory 生成記事の典型的な差分

Article Factory（AI自動生成）が作成した記事には、以下の差分が多く見られます。

| 差分項目 | Article Factory版 | テンプレートv2版 |
|---|---|---|
| タイトルID形式 | `#R02-010`（`update_release02_draft_ids.py` 適用後） | `#2_010` ← **要修正** |
| 映像メタデータ形式 | パイプ区切り単行 | 拡張箇条書き |
| ffprobe パイプ残留 | `解像度：X（FHD）| フレームレート：Y` | 2行分割形式 ← **T12で自動修正** |
| 冒頭注釈フレーズ（視覚）| なし | `以下は映像フレームの目視確認によるものです。` |
| 冒頭注釈フレーズ（ファイル名）| なし | `以下の情報はファイル名および...` |
| 注意点セクション | 存在しない | `## 注意点` 必須 |
| ディスクレイマー | 1行のみ（内容概略） | 3段落（PR050/051準拠） |
| 画像プレースホルダー | なし or 旧形式 | `▼ 【画像】...` + `掲載画像：` 行 |
| 出典の画像表記 | `代表フレーム：thumbnails/...` | `掲載画像出典：...より抽出` |
| ▲キャプション語尾 | 普通体（確認できる）混在 | **必ずです・ます調（確認できます）** ← T13 |
| DVIDS ID注記（メタ行） | `（DVIDS＝国防映像情報配信サービス）` | `（DoW/DVIDS管理番号）` ← T14 |
| DVIDS ID注記（由来行） | `- DVIDS ID：XXXXX` | `- DVIDS ID（DoW/DVIDS管理番号）：XXXXX` ← T15 |
| AI解析メモフレーム記録 | `（Nフレーム）` | タイムコード列挙 ← T16 |
| 注意点→出典間セパレータ | なし/不統一 | `---` 必須 ← T17 |

## 6. バリデーションチェックリスト（記事単位）

```
【構造チェック】
[ ] タイトルに #2_XXX 形式（R02-XXX ではない）
[ ] Release Date に「・Release 02」が含まれている

[ ] 「以下は映像フレームの目視確認によるものです。」が存在する
[ ] 「以下の情報はファイル名および...映像フレームから直接確認したものではありません。」が存在する

[ ] ffprobe解像度行にパイプ（|）が含まれていない
[ ] 「ffprobeによる技術情報を以下に示します。」が存在する
[ ] ## 注意点 セクションが存在する（最低4項目）
[ ] ## 注意点 と ## 出典 の間に --- が存在する
[ ] ディスクレイマーが3段落形式（「映像内容の判断には...」「今後...」「原文リンクを...」）

[ ] DVIDS ID が「（DoW/DVIDS管理番号）」付きで記載されている（メタデータ行）

[ ] AI解析メモに「DVIDS ID XXXXXXX」が含まれている
