# Codex 監査チェックリスト v1.0

**制定日**: 2026-05-13  
**参照**: `docs/codex_audit_role.md`, `docs/review_standard_v1.md`

---

## 使い方

- **監査前に `review_logs/codex_feedback_log.md` を確認すること**
  - `Human Decision: Rejected` の指摘と同種のWARNを出していないか確認する
  - ルール反映済み（`Status: Reflected`）の項目はそのルールを優先する
- 各記事に対してこのチェックリストを順番に実施する
- 各項目を ✅ PASS / ⚠️ WARN / 🔴 BLOCK / ❓ UNVERIFIABLE で判定する
- 結果を `review_reports/codex_audit_{YYYYMMDD}_{scope}.md` に出力する

## Phase 1: Provenance Audit（一次資料整合性）

### P1-1. メタデータ整合性

| チェック項目 | 判定基準 |
|------------|---------|
| ファイル名が source_registry.csv の pdf_file_name と一致しているか | 不一致 → 🔴 BLOCK |
| Source URL が WAR.GOV トップページ（https://www.war.gov/UFO/）ではなく、対象PDFの直接URL（https://www.war.gov/medialink/ufo/release_1/<filename>）になっているか | トップページURL → 🔴 BLOCK |
| 機密解除日・AARO公開承認日の記述形式が統一されているか（YYYY年MM月DD日） | 形式不正 → ⚠️ WARN |
| Incident Date が記事本文の観測日時と矛盾していないか | 矛盾 → 🔴 BLOCK |
| Incident Location に MGRS が含まれる場合、初出で `MGRS〔軍用地図座標系〕` と補足されているか | 未補足 → ⚠️ WARN |

### P1-2. 数値・単位の信頼性

| チェック項目 | 判定基準 |
|------------|---------|
| FL記法が `FL240（フライトレベル240・高度約7.3km）` 形式になっているか | `FL240（24,000フィート…）` 形式 → 🔴 BLOCK |
| 速度・高度の換算値が括弧内に補助換算として記述されているか | 換算値のみで原文値がない → 🔴 BLOCK |
| 推定値（Estimated）が「推定値」と明記されているか | 未明記 → ⚠️ WARN |
| `（英語 expansion）` の括弧内英語がソース PDF に存在する確認が取れているか | 未確認 → ⚠️ WARN（公知略語は例外） |
| 日付・時刻（Zulu時刻）が記事内で一貫しているか | 不一致 → 🔴 BLOCK |

### P1-3. 固有名詞・略語

| チェック項目 | 判定基準 |
|------------|---------|
| 基地名（OMAM, OJMS, OKAS等）がICAOコードと地名の両方で記述されているか | 片方のみ → ⚠️ WARN |
| 部隊名（389 EFS, 482 ATKS等）が初出時に正式名称で補足されているか | 未補足 → ⚠️ WARN |
| MGRS座標が `MGRS（軍用地図座標系）` と初出で説明されているか | 未説明 → ⚠️ WARN |
| 機密区分（SECRET//NOFORN 等）が注意点で説明されているか | 未説明 → ⚠️ WARN |

### P1-4. 番号・コード類（#036以降必須）

| チェック項目 | 判定基準 |
|------------|---------|
| Misrep番号が「米軍の任務報告番号『Misrep …』として記録されています」形式か | 「識別されます」等 → 🔴 BLOCK |
| MDR番号が「公開・機密解除管理番号『MDR …』」として説明されているか | 未説明 → ⚠️ WARN |
| JSIR番号が「統合特別情報報告番号」として説明されているか | 未説明 → ⚠️ WARN |
| CSP/MRO等その他番号類に「何の番号か」の説明があるか | 未説明 → ⚠️ WARN |

### P1-5. 重複・転記チェック

| チェック項目 | 判定基準 |
|------------|---------|
| source_registry.csv で当該 PDF が BLOCK 状態でないか | BLOCK → 🔴 BLOCK |
| 同一 PDF が別の記事番号でも存在しないか（SHA256 重複） | 重複 → 🔴 BLOCK |
| ファイル名が異なる別URLで同一内容のPDFが raw_pdf/ に存在しないか（MD5クロスチェック） | 重複 → 🔴 BLOCK |
| 公開済み記事と内容の重複がないか | 重複 → ⚠️ WARN |

**【既知リスク】war.gov側起因の異ファイル名重複について**

war.govが同一内容のPDFを異なるファイル名・URLで二重掲載している事例が確認されている（#069事例: `59_214434_sp_16_7.18.1963.pdf` と `59_214434_sp_16_[7.18.1963].pdf`、MD5完全一致・2026-05-14確認）。

この種の重複はファイル名ベースの一意性チェックでは検出できず、SHA256/MD5によるバイト単位の照合が必要。新規バッチのダウンロード時点で `raw_pdf/` 内の既存ファイルとのMD5クロスチェックを実施することを推奨する。重複が確認された場合は `status=duplicate_of_NNN` として source_registry.csv に記録し、記事は作成しない。

### P2-1. 記事構成

| チェック項目 | 判定基準 |
|------------|---------|
| 構成が「メタデータ → 要点 → AI読解 → 注意点 → 出典 → 免責」の順か | 欠落 → ⚠️ WARN |

| 出典セクションに元PDF URLと元PDFファイル名があるか | ない → 🔴 BLOCK |

| AARO が初出時に「全領域異常解決局／米国防総省のUAP調査組織」と補足されているか | 未補足/意味不足 → ⚠️ WARN |
| USCENTCOM が初出時に「米国中央軍。中東・中央アジア周辺を担当する米軍の統合軍」と補足されているか | 未補足/意味不足 → ⚠️ WARN |
| MISREP が初出時に「軍の任務報告書」と説明されているか | 未説明 → ⚠️ WARN |
| GENTEXT が初出時に「報告書内の自由記述欄」と説明されているか | 未説明 → ⚠️ WARN |
| FMV が初出時に「フルモーション映像。静止画ではなく短い動画クリップとして記録された映像」と説明されているか | 未説明/意味不足 → ⚠️ WARN |
| positive identification が「対象を明確に識別すること」と説明されているか | 未説明 → ⚠️ WARN |
| platform を、根拠なく航空機・車両・ドローン等に具体化していないか | 根拠なき具体化 → 🔴 BLOCK |
| DCA・AREC・RECCE等の任務種別略語が説明されているか | 未説明 → ⚠️ WARN |

| MGRS・MDR・JSIR・HVI・POI・FVEY・NOFORN 等の略語が初出時に補足されているか（#041以降） | 未補足 → ⚠️ WARN |
| RTB が初出時に `Return To Base` または「基地へ帰投」と説明されているか（#042以降） | 未説明 → ⚠️ WARN |
| FVEY が初出時に「Five Eyes共有」と説明されているか（#042以降） | 未説明 → ⚠️ WARN |

### P2-3. 表現の客観性・中立性

| チェック項目 | 判定基準 |
|------------|---------|
| 「UFO」「宇宙人」「異星人」等のUFO論壇的表現が使われていないか | 使用 → 🔴 BLOCK |
| センサー観測結果が「観測された」ではなく「記録された」で表現されているか | 誇張表現 → ⚠️ WARN |
| 乗員評価（Benign/POSS/UNK）が確定事実として書かれていないか | 確定表現 → 🔴 BLOCK |
| 「Under Intelligent Control: NO」が「何も操縦していない」ではなく「そのように見えない」評価として書かれているか | 過剰解釈 → ⚠️ WARN |
| 推測・解釈と確認事実が明確に区別されているか | 混在 → ⚠️ WARN |

### P2-4. 単位換算・スケール感翻訳

| チェック項目 | 判定基準 |
|------------|---------|
| ノット → km/h の換算が正しいか（1 KT = 1.852 km/h） | 誤差 5% 超 → ⚠️ WARN |
| MPH → km/h の換算が正しいか（1 MPH = 1.609 km/h） | 誤差 5% 超 → ⚠️ WARN |
| フィート → m / km の換算が正しいか（1 ft = 0.3048m / 0.0003048km） | 誤差 5% 超 → ⚠️ WARN |
| 換算値が括弧内補助情報（LOW provenance）として明記されているか | 換算値を原文値と同等に扱っている → ⚠️ WARN |
| 大きな重量・燃料量（ポンド・ガロン等）に「約〇〇トン」等のスケール感補足があるか（#040以降） | 補足なし → ⚠️ WARN |
| 換算値が過度に精密でないか（「36,967kg」等）（#040以降） | 精密すぎる換算 → ⚠️ WARN |
| feet / miles / miles/sec / miles/hour / inches / pounds / Fahrenheit / AGL などが本文中に出るたび日本向け換算付きになっているか | 換算なし → ⚠️ WARN |
| 同じ段落内で同じ単位が連続する場合、最初の1回に換算があるか | 段落内の初回も換算なし → ⚠️ WARN |

**スケール感翻訳の判断基準（#040以降）：**  
目的は単位の正確な変換ではなく、一般読者が規模感をイメージできること。「約37トン」「約30.5km」「時速約785km」のように丸めた表現を優先する。Release 02 以降は、初出時だけでなく本文中に出るたびに換算を併記する。ただし同じ段落内で同じ単位が連続する場合は最初の1回でよい。`review_logs/codex_feedback_log.md` エントリ [20260513-001] 参照。

## 記事種別ごとの追加チェック

### 限定情報記事（ほぼ全面非公開）

| チェック項目 | 判定基準 |
|------------|---------|
| 冒頭に「⚠️ 限定情報記事について」のセクションがあるか | ない → 🔴 BLOCK |
| 公開情報のみを根拠として記述しているか | 非公開情報を推測で記述 → 🔴 BLOCK |
| AI解析メモに残存テキスト文字数が記録されているか | ない → ⚠️ WARN |

### OCR不可記事（スキャン画像PDF）

| チェック項目 | 判定基準 |
|------------|---------|
| 冒頭に「⚠️ テキスト抽出不可の記事について」のセクションがあるか | ない → 🔴 BLOCK |
| ファイル名以外の情報を事実として記述していないか | 記述あり → 🔴 BLOCK |
| 背景・作成主体・歴史的位置づけを外部知識で補っていないか | 本文事実化 → 🔴 BLOCK / 外部背景区分なし → ⚠️ WARN |
| 同一シリーズ構成・前後関係を source_registry または確認済みPDFなしに推定していないか | 推定記述あり → ⚠️ WARN / 本文中心なら 🔴 BLOCK |
| `Record Group`、`FBI番号体系`、`NARA`、`Project Sign`、`JFK政権期` 等の外部背景混入がないか | 本文事実化 → 🔴 BLOCK / 背景区分なし → ⚠️ WARN |
| AI解析メモに「テキスト0文字（スキャン画像PDF）」の記録があるか | ない → ⚠️ WARN |

### 画像記事（静止画・映像フレーム）

| チェック項目 | 判定基準 |
|------------|---------|
| 視覚観察（暗点・位置・リダクション・画面表示）と解釈（物体種別・機器動作・同一性）が分離されているか | 混在 → ⚠️ WARN |
| 「移動」「追跡」「消失」「分裂」「複数化」等を確定事実として書いていないか | 断定 → ⚠️ WARN |
| 「ヘリコプター」「センサーアーティファクト」「ズーム倍率」等の機器・物体解釈に根拠があるか | 根拠なし → ⚠️ WARN / 重大なら 🔴 BLOCK |
| 画像のみの判断に「見える」「可能性がある」等の留保があるか | 留保なし → ⚠️ WARN |

### 背景資料記事（非UAP文書）

| チェック項目 | 判定基準 |
|------------|---------|
| 冒頭に「⚠️ この記事について」＋「本資料はUAP目撃事案の報告書ではありません」があるか | ない → 🔴 BLOCK |
| WAR.GOV UAP公開コレクションに含まれる理由の説明があるか | ない → ⚠️ WARN |

### #091以降：軽量レビュー方式

#091以降は、以下の軽量レビュー方式を標準とする。

- PASS: 1行のみ
- WARN: 記事番号 + 問題種別 + 一言のみ
- BLOCK: 詳細出力

既知ルール違反は記事ごとに繰り返さず、コード単位で集約する。

```
W-07: 追跡対象物
#091 #093 #095
```

禁止:

- 全記事長文説明
- 修正不要箇所説明
- 同じ説明の繰り返し
- 全文レビュー

重点チェック:

- OCR不可: ファイル名外情報 / Record Group断定 / 歴史背景混入 / 系列構成断定
- 画像記事: EO/IR断定 / 追跡対象 / 捕捉 / ロック / 軍用IR

指摘は原則として短く出す。

- セクション名
- 該当文
- 修正案

既出ルール違反は、指摘または理由に「反復違反」と明記する。

# Codex 監査レポート {YYYYMMDD} — {scope}

**監査対象**: #XXX〜#YYY
