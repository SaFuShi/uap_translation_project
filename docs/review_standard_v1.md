## note投稿互換フォーマット（今後の note_drafts 全記事必須）

note のブラウザ投稿画面へのコピペ時に本文欠落・空白化・レイアウト崩れが発生するため、今後の `note_drafts/` では以下を禁止する。

### 禁止事項

- **Markdown table**（`| col | col |` 形式）→ note で空白化・欠落が発生する
- **引用ブロック**（`>` で始まる行）→ note で崩れが発生する
- **長い英文引用**（目安200字超）→ note で本文欠落・空白化の原因になりやすい
- **複雑なネスト箇条書き**（2階層以上の `-` ネスト）→ note で崩れが発生する
- **Codex注釈ブロック**（`[!REVIEW-*]`）→ note_drafts には含めない（review_reports/annotated/ 専用）

### 代替フォーマット

**表の代替：**
```
# NG
| 項目 | 内容 |
|------|------|
| 日付 | 2023年9月16日 |

# OK
【文書の基本情報】
- 日付：2023年9月16日
```

**引用ブロックの代替：**
```
# NG
> "Congress heard testimony on UAP..."

# OK
【原文抜粋】
"Congress heard testimony on UAP..."

【要訳】
メキシコ議会がUAPに関する証言を聴取した。
```

長い英文は全文引用せず、必要な最小限の抜粋にする。長い原文確認が必要な場合は、本文では要約し、原文PDFリンクで確認させる。

## AI概要版メタデータ定型ルール（全記事必須・#048以降適用）

ドラフト生成段階で必ず満たすこと。Codex監査では BLOCK 判定対象。

### Source URL

文書メタデータの `Source URL` には、必ず対象 PDF の**直接 URL** を記載する。

```
# NG: トップページ
- Source URL： https://www.war.gov/UFO/

# OK: PDF 直接 URL
- Source URL： https://www.war.gov/medialink/ufo/release_1/<pdf_file_name>
```

WAR.GOV トップページは `出典` セクションに残してよいが、メタデータの Source URL は直接 PDF URL に統一する。

### Incident Location の MGRS 初出補足

文書メタデータの `Incident Location` に MGRS 座標が含まれる場合は、初出で必ず `MGRS〔軍用地図座標系〕` と補足する。

```
# NG: 補足なし
- Incident Location： シリア（MGRS 37SFU付近）

# OK: 初出補足あり
- Incident Location： シリア（MGRS〔軍用地図座標系〕37SFU付近）
```

複数 MGRS の場合も同様：
```
- Incident Location： UAE（MGRS〔軍用地図座標系〕39RXK〜39RYJ付近）
```

## Phase 1：事実整合性レビュー / provenance audit

### 目的

PDF原文・OCRテキスト・記事本文の整合性を確認し、重大な誤情報を止める。

### 見るもの

- source_text に存在しない具体的事実
- hallucination（AI作話）
- 別PDF由来と思われる記述の混入
- OCR誤読
- 日付・時刻
- 距離・高度・速度
- 機数
- 固有名詞
- 指揮官評価
- PDF内の表記不一致
- 原文値が消えて換算値だけになっていないか

### 見ないもの（Phase 2に委ねる）

- 日本語としての自然さ
- 一般読者にとって分かりやすいか
- 軍事略語が読みにくいか
- 表現のやわらかさ
- note記事としての読みやすさ

---

### Phase 1 リスク分類

#### 🔴 HIGH — 公開前に必ず修正

- source_text に存在しない具体的事実
- 本文にない日付・時刻
- 本文にない距離・高度・速度
- 本文にない機数
- 本文にない固有名詞
- 別PDF由来と思われる記述
- contrail / 100,000ft のような不自然な混入
- 原文値が記事から消えて換算値だけになっているもの
- 原文と逆の意味になる要約

#### 🟡 MEDIUM — 確認推奨。公開停止まではしない。

- OCR誤読の可能性があるが判断保留のもの
- 固有名詞の表記ゆれ
- 略語展開の不確実性
- PDF内で数値に揺れがあるもの
- 画像PDF・疎テキストPDFで目視確認が望ましいもの

#### 🟢 LOW — 原則許容

- 括弧内の概算換算（数値・単位表記ルール v1 参照）
- 日本語読者向けの軽い補足
- 文意を変えない言い換え
- 原文値を保持したうえでの補助説明

---

### Phase 1 チェックツール

```bash
python3 scripts/generate_provenance.py <ドラフトファイル.md>
```

HIGH が出た場合は**公開前に内容を確認・修正**する。  
MEDIUM は内容を確認し、問題なければ公開可。LOW は許容。

## Codex監査方針：重点チェック

### OCR不可記事

OCR不可記事では、ファイル名・PDFメタデータから確認できる範囲を超えた記述を重点チェックする。

以下は WARN / BLOCK 候補とする。

- ファイル名以外の事実を、確認済み事実として書いている
- 文書の背景・作成主体・歴史的位置づけを外部知識で補っている
- 同一シリーズの構成や前後関係を、source_registry または確認済みPDFなしに推定している
- `Record Group`、`FBI番号体系`、`NARA`、`Project Sign`、`JFK政権期` などの外部背景を本文事実として混入させている

判定目安：

- OCR不可なのに、ファイル名から読み取れない具体的内容を本文の中心にしている → BLOCK
- 外部背景として有用だが、出典区分や推定であることが不明確 → WARN
- 背景説明が必要な場合は、「本文資料から確認できる情報」と「外部背景」を明確に分ける

### 画像記事

画像記事では、視覚観察と機器・物体解釈を分離して評価する。

許容しやすい表現：

- 画面上に小さな暗点が見える
- クロスヘア右上付近に位置しているように見える
- スケール表示が `±15` から `±3` に変わっている

注意が必要な表現：

- 物体が移動した
- 対象を追跡している
- ヘリコプターである
- ズーム倍率が5倍である
- センサーアーティファクトである
- 対象が消失した、分裂した、複数化した

画像のみから判断している場合は、「見える」「ように見える」「可能性がある」に留める。機器仕様・物体同一性・カメラ操作・対象物の運動は、資料内テキストや別途根拠がない限り断定しない。

### 反復違反

過去のフィードバックログや review_standard に反映済みのルールに再び違反している場合、Codexは指摘内で「反復違反」と明示する。

対象例：

- Source URL が直接PDF URLではない
- MGRS 初出補足漏れ
- ISR / MISREP / FVEY / RTB / 1.4(a) などの初出補足漏れ
- OCR不可記事でファイル名以外の推定を本文事実として書く
- Markdown table、引用ブロック、長い英文引用、Codex注釈ブロックの混入

### 指摘の出し方

修正指摘は短く、採否判断しやすい形にする。

最低限、以下を含める。

- セクション名
- 該当文
- 修正案

長い説明は避け、理由は1文程度に圧縮する。既出ルール違反の場合は、理由に「反復違反」と明記する。

## Phase 2：可読性レビュー / 日本語UXレビュー

### 目的

一般の日本語読者が、軍事文書・UAP文書として無理なく読めるかを確認する。

### 見るもの

- 日本語として自然か
- 軍事直訳で意味不明になっていないか
- 略語に最低限の補足があるか
- 見慣れない単位に補助換算があるか
- 大きな数値について、一般読者が規模感をイメージできる補助換算があるか
- note記事として読みやすいか
- 煽りすぎていないか
- 「UFO確定」「異星由来」などに見えないか
- 原因不明を断定していないか
- 一般読者がもやっとする箇所がないか

### 修正基準（具体例）

| NG | OK |
|---|---|
| KCTGの標準活動 | 米軍側任務部隊（KCTG）の既知の活動範囲と一致する、想定内の活動 |
| 相互作用は安全だった | 危険な接近や衝突リスクは確認されなかった |
| 500ノットで飛行 | 500ノット（時速約930km）で飛行 |
| 40海里付近で視認を失った | 40海里（約74km）付近で視認を失った |

### Phase 2 追加基準：番号・コード類の説明（#036以降適用）

軍内部のコード体系（報告番号・管理番号・識別コード等）は、一般読者には意味が見えない。初出時に「何の番号か」を必ず説明する。

**目的：** 「軍内部では当たり前のコード体系」を、一般読者が意味を理解できる形へ変換する。

#### 対象と標準表記

| コード類 | 非推奨（そのまま） | 推奨（説明付き） |
|---|---|---|
| Misrep + 番号 | Misrep 9329374 | 米軍の任務報告番号「Misrep 9329374」 |
| MRN + 番号 | MRN 94 DUSHANBE 259 | 外交電報管理番号「MRN 94 DUSHANBE 259」 |
| MDR + 番号 | MDR 25-0094〜25-0099 | 公開・機密解除管理番号「MDR 25-0094〜25-0099」 |
| CSP + 番号 | CSP 12345 | 初出で用途説明（文脈による） |
| Event Serial | Event Serial 001 | 初出で「事案識別番号」等の説明 |
| JSIR | JSIR 番号 | 初出で「統合特別情報報告書番号」等の説明 |
| Task Force code | TF CHOSIN | タスクフォース（任務部隊）名称。「チョーサン」等のカナ表記を付ける |

#### 動詞の使い方

「識別されます」より「記録されています」のほうが一般読者に自然。

| 非推奨 | 推奨 |
|---|---|
| Misrep undefined-7816710として識別されます | 米軍の任務報告番号「Misrep undefined-7816710」として記録されています |

### Phase 2 追加基準：SF/UFO論壇用語の言い換え（#035以降適用）

軍事・外交文書の直訳によって生じる「SF用語」「UFO論壇用語」「軍事翻訳臭」のある表現を、一般読者向けの自然な日本語へ変換する。

**目的：** 「軍事・外交文書を日本語へ直訳すること」ではなく、「一般読者が一次資料の内容を誤解なく理解できること」。

#### 言い換え基準（#035以降）

| 非推奨（直訳・論壇用語） | 推奨（一般読者向け） |
|---|---|
| 宇宙起源 | 地球外由来である可能性 |
| 知的制御下 | 何者かが意図的に制御している可能性 |
| 知的制御下にある | 意図的に操縦されているように見える |
| extraterrestrial and under intelligent control | 地球外由来で、何者かが意図的に制御している可能性がある |
| 宇宙起源・知的制御下 | 地球外由来で、何者かが意図的に制御している可能性がある |

**判断した・確認した・断定した** の使い分け：

外交電報・MISREPでは、目撃者/乗員の発言と政府・機関の公式評価を区別すること。

| 主体 | 推奨動詞 |
|---|---|
| 乗員・目撃者の発言（witness statement / crew assessment） | 述べた・考えた・推定した |
| 機関の公式評価（embassy assessment / official assessment） | 評価した・判定した |
| 使用禁止（断定を避ける） | 判断した・確認した・断定した |

#### チェックリスト（#035以降追加）

- [ ] 「宇宙起源」「知的制御下」など直訳のSF/UFO論壇用語が残っていないか
- [ ] 目撃者発言と公式評価が混在していないか（「述べた」vs「評価した」）
- [ ] 直訳が「断定」に見えていないか

| 単位 | 義務 | 例 |
|---|---|---|

### Phase 2 追加基準：スケール感翻訳（#040以降適用）

単位を日本語へ変換することではなく、**一般読者が規模感・異常性・大きさを感覚的に理解できること**を目的とする。

**目的：** 数値を正確に変換するのではなく、読者が「どれくらいの規模か」をイメージできるようにする。

#### 対象となる数値の例

| 単位・数値 | スケール感翻訳例 |
|-----------|---------------|
| 81,500 ポンド（燃料） | 約37トン |
| 100,000 フィート（高度） | 約30.5km |
| 424 ノット（速度） | 時速約785km |
| 5 NM（距離） | 約9km |

#### NG（避けるべき表現）

```
# NG: 過度に精密な計算値（読者の感覚に届かない）
36,967kg
81,500lb = 36,967.5kg
```

#### 推奨（読者の感覚に届く表現）

```
# 推奨: 丸めたスケール感のある値
約37トン
約30.5km
時速約785km
```

#### 適用判断の基準

- **換算が必要**：一般読者が規模感をイメージできない大きな数値（重量・燃料量・長距離など）
- **換算不要**：文脈から規模感が明らかな場合、または前後で既に換算済みの場合
- **機械的に全換算しない**：読者理解に寄与する場合のみ追加する

#### チェックリスト（#040以降追加）

- [ ] 大きな重量・燃料量（ポンド・ガロン等）に「約〇〇トン」等の補足があるか
- [ ] 距離・高度の数値から読者が規模感をイメージできるか
- [ ] 速度換算が単なる単位変換ではなく、感覚的な速さとして伝わるか
- [ ] 「36,967kg」のような過度に精密な換算値を使っていないか

| FVEY | FVEY（Five Eyes共有） |

| RTB | RTB（Return To Base：基地へ帰投） |
| 1.4(a) / 1.4(g) | 国家安全保障上の理由（1.4(a)・1.4(g)区分） |

#### 原則

- **記事単独で読んでも意味が通ること**を最優先にする
- 同一記事内で複数回出現する場合は、初出のみ補足し、2回目以降は略語のみでよい
- 上記リストにない略語でも、一般読者に不透明な場合は同様に補足する

### Phase 2 追加基準：OCRログ・英文引用の構造化（#036以降適用）

軍事ログ・OCRログ・GENTEXT・MISREP本文を引用する場合、原文をそのまま貼るのではなく、**情報構造を人間向けに整理してから引用する**。

**目的：** OCRログの再掲ではなく、一般読者が一次資料を理解できること。

#### 禁止

```
「(SECRET//REL TO USA, FIN, SWE, FVEY, NATO) AT 1653Z, OBS 2X ROUND WHITE HOT UAPS DYNAMIC SOUTH AT APPROX 240NM/HOUR IVO 35SQT...」と記述されています。
```

GENTEXT・SECRET表記・軍略語・MGRSなどのOCRノイズをそのまま並べた全文引用は行わない。

#### 推奨構造

1. 「GENTEXT（自由記述欄）には以下が記録されています」と見出しを立てる
2. 箇条書きで情報要素を日本語で整理する（時刻・物体の描写・速度・方向・座標など）
3. 必要な場合のみ、最小限の原文を `【原文抜粋】` として通常テキストで記載する
4. 和訳・要約は `【要訳】` として通常テキストで記載する

```markdown
公開されている観測記録（GENTEXT：自由記述欄）には、以下の内容が記録されています。

- 1653Zの観測時刻
- 2機の「ROUND WHITE HOT UAPS（赤外線センサーで白熱表示された円形UAP）」
- 南方向への移動・約240ノット（時速約445km）の速度

原文では以下のように記述されています。

【原文抜粋】
"OBS 2X ROUND WHITE HOT UAPS DYNAMIC SOUTH AT APPROX 240NM/HOUR"

【要訳】
2機の赤外線上で白く表示された円形UAPが、南方向へ約240ノットで移動していたと記録されています。
```

#### GENTEXT の初出補足

初出時は必ず `GENTEXT（自由記述欄）` と補足する。

#### チェックリスト（#036以降追加）

- [ ] 軍事ログ全文をそのまま引用していないか
- [ ] SECRET表記・REL TO・OBS・IVO などの略語が説明なく並んでいないか
- [ ] GENTEXT の初出に「（自由記述欄）」補足があるか
- [ ] 情報要素が日本語の箇条書きで整理されているか
- [ ] 原文引用が `>` 引用ブロックではなく `【原文抜粋】` 通常テキストになっているか
- [ ] 和訳・要約が `【要訳】` 通常テキストになっているか
- [ ] 長い英文引用を本文に貼り付けていないか

## 数値・単位表記ルール v1

> 詳細: `scripts/UNIT_NOTATION_RULES_v1.md`

### 原則

原文にある数値・単位を**主表記**として残す。

```
31,000フィート
FL160〜FL170
500ノット
55海里
50ヤード
```

### 括弧内の補助換算（許可）

日本語読者向けに括弧内で概算換算を入れてよい。

```
31,000フィート（約9.4km）
FL160〜FL170（高度約4.9〜5.2km）
500ノット（時速約930km）
55海里（約102km）
50ヤード（約45メートル）
80MPH（約70ノット・時速約130km）
424ノット（時速約785km）
81,500ポンド〔約37トン〕
```

#### 速度表記の追加ルール（#032以降）

MPH・ノット単位の速度は、ノットだけでは日本人読者に速度感が伝わりにくい。
**km/h 換算を必ず加える。**

| 原文 | 表記例 |
|---|---|
| 80 MPH | 約80MPH（約70ノット・時速約130km） |
| 500 KTS | 500ノット（時速約930km） |
| 424 KN | 約424ノット（時速約785km） |
| 277 MPH | 時速277マイル（約446km/h） |

MPH とノットを両方示す場合は `MPH（ノット・km/h）` の順で記載する。

### 禁止

```
# NG: 原文値が消えている
高度9,450メートルを飛行
時速926kmで飛行
ラタキア北西102km
約45メートル先（原文: 50 yards が消失）

# NG: 過度に精密な換算
時速926.0kmで飛行
```

### provenance上の扱い

括弧内の換算値はAI補助換算として扱い、リスクは **LOW**。  
以下の場合のみ WARNING にする：

- 原文値が本文から消えている → HIGH
- 換算値だけが残っている → HIGH
- 換算値が過度に精密 → MEDIUM
- 換算式が明らかに誤っている → HIGH
- 原文単位と違う意味に変わっている → HIGH

## 重要な考え方

AI概要版は詳細解析版ではない。

**優先すること:**
- 一次資料と矛盾しない
- 一般日本語読者が読める
- OCR不確実性を明示する
- 原文リンクで確認できる

**許容しないこと:**
- source_text に存在しない具体的事実の混入
- 原文値を換算値に置き換えて原文値を消す
