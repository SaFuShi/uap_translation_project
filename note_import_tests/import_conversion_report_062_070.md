## noteインポート時の注意点

### TITLE表示

- MTの `TITLE:` フィールドがnoteの記事タイトルになる
- 固定形式「【AI概要版 #NNN】_米国防総省が公開したUFO関連ファイルを日本語訳してみる」が正しく入力されているか確認
- 全角文字・`【】`・`_` の文字化けがないか確認

### BODY先頭の `#` 見出し

- BODY先頭に各記事固有のタイトル見出し（`# ...`）が残っている
- noteが `#` をH1見出しとして認識するか、またはテキストとして表示するか確認が必要
- #061のPoCでは `#` 見出しがBODYに残る形式で問題なく確認済み

### Markdown変換

- `CONVERT BREAKS: markdown` を指定
- `##` 見出し・`**太字**`・箇条書きが正しく変換されるかはインポート後に要確認
- `---` 水平線がnoteで表示されるかは#061 PoCで要確認

### `【抽出テキスト全文】`ブロック（#062のみ）

- コードブロック（``` ```）をプレーンテキストの `【抽出テキスト全文】` 形式に変換済み
- noteでのコードブロックレンダリングが不安定なためプレーンテキスト化
- 英文テキストが正しく表示されるか確認

### ⚠️ 絵文字

- `⚠️` を含む見出しが全記事に含まれる
- #061 PoCで ⚠️ 絵文字は問題なく確認済み（本文欠落なし）
