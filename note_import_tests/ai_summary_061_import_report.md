## PoC結果・追記（2026-05-14）

### インポート結果

- **noteインポート自体は成功**（.txt拡張子でアップロード可能なことを確認）
- `.mt` 拡張子はnoteのインポート画面でファイル選択・ドラッグアップロード不可。`.txt` 拡張子が必要。

### MT生成ルール変更

インポート成功後、noteの記事タイトル運用に合わせてMT生成ルールを以下に変更：

**変更前（初回生成）:**
- `TITLE:` = ドラフト1行目の `# ` 見出しをそのまま使用
- `BODY:` = タイトル行を除いた本文のみ

**変更後（確定ルール）:**
- `TITLE:` = 固定フォーマット：`【AI概要版 #NNN】_米国防総省が公開したUFO関連ファイルを日本語訳してみる`
- `BODY:` = ドラフトの `# ` 見出し行をBODY先頭に **残す**（TITLEフィールドとは別に保持）

**理由：** noteの記事タイトルはシリーズ名として統一運用するため、`TITLE` フィールドには固定文字列を使用。ドラフト見出し（記事内容を示すタイトル）はBODY内の `#` 見出しとして表示する。

### 再生成ファイル

- `.mt` ファイルを新ルールで再生成済み
- `.txt` ファイル（インポート用）を `.mt` と同一内容に更新済み
